# ワードローグ / Wordrogue

> 言葉を組み合わせて武装する 2D ローグライク。
> **作った「文」が成立しなければ、その武器は無効になる。**

Vampire Survivors 系の放置アクションに、**日本語の文を組み立てる**仕組みを乗せたもの。
外部ライブラリなし・ビルド不要・画像ファイルなしの、依存ゼロのブラウザゲーム。

---

## 遊びかた

### 1. 文がそのまま武器の名前になる

武器には **枠** がある。枠に語を並べると、それがそのまま **武器名** になる。
核語は無い。武器レベルに応じて **4 → 7 枠**。

| 並べた語 | 武器名 | 結果 |
| --- | --- | --- |
| 刃 + 利 | `刃利剣` | **成立** — 斬撃 |
| 爆裂 + 無双 + 雷 | `爆裂無双雷剣` | **名文** — 爆発する雷の斬撃 |
| 炎 + 分裂 + 散弾 | `炎分裂散弾銃` | **名文** — 拡散して貫通する炎の弾 |
| 火 + 球 | `火球剣` | **名文** — 熟語「火球」ボーナス |
| 刃 の み | `刃のみ剣` | **不成文** — 実質語 1 つ。攻撃しない |
| の + は | `のは剣` | **不成文** — 助詞だけ |

**成立の判定は 2 つ。** 連結した文字列が

1. 辞書で**完全に分割できる**（例: `爆裂無双迅剣` → `爆裂` / `無双` / `迅` / `剣`）
2. **実質語（助詞でも助動詞でもない語）を 2 つ以上**含む

末尾語も実質語として数えるので、成立には **枠の側で実質語を 2 つ以上** 置く必要がある
（末尾語ぶん要求が 1 つ多い）。

**末尾語だけが攻撃を決める。** 途中に別の形態語を並べても攻撃は変わらず、
効果（貫通・巨大・分裂など）だけが加わる。
`刃` + `利` + `爆弾` は「刃利爆弾剣」で、この武器は**斬撃**のまま（爆発は付く）。

| 語 | 効果 | 語 | 効果 |
| --- | --- | --- | --- |
| 剣 刃 刀 太刀 | 斬撃 | 弾 矢 針 球 | 射撃 |
| 爆弾 彗星 | 爆弾 | 雷 雷神 | 連鎖 |
| 環 回転 | 軌道 | 鞭 嵐 | 薙ぎ |
| 壁 棘壁 | 城壁 | 光線 閃光 | 光線 |
| 銃 | 射撃 | 弓 環刃 | 射撃・還刃 |

### 2. 末尾の語は武器ごとに固定

武器名の**末尾の語**は枠の外に固定で付く。並べ替えても動かない。
だから**名前と攻撃の型が必ず一致する**。

| 武器 | 末尾語 | 攻撃 |
| --- | --- | --- |
| 剣 | `剣` | 斬撃 |
| 銃 | `銃` | 射撃 |
| 弓 | `弓` | 射撃 |
| 爆弾 | `爆弾` | 爆弾 |
| 回転刃 | `環` | 軌道 |
| 雷 | `雷` | 連鎖 |
| 鞭 | `鞭` | 薙ぎ |
| 棘壁 | `壁` | 城壁 |
| 環刃 | `環刃` | 還刃 |
| 光線 | `光線` | 光線 |

**末尾語だけが攻撃を決める。** 途中に別の形態語を並べても攻撃は変わらず、
効果（貫通・巨大・分裂など）だけが加わる。
`刃` + `利` + `爆弾` は「刃利爆弾剣」で、この武器は**斬撃のまま**（爆発は付く）。

### 3. 語の種類

| 種別 | 例 | 効果 |
| --- | --- | --- |
| 属性 | 火 灼熱 猛毒 | 色と状態異常（炎上・減速・感電・毒） |
| 形態 | 剣 銃 弓 弾 矢 球 環 壁 | 効果と末尾語になる。**攻撃は末尾語だけ** |
| 効果 | 巨大 貫通 分裂 散弾 | 数値を上げる |
| 動詞 | 燃える 貫く 凍る 爆裂 | 1 枚で 1 つの動作になる |
| 接続 | スル ノ サレタ イ | **直前の語に結合する**（次項） |
| 自身 | 頑強 疾走 護符 | プレイヤーに効く |


**文の力**は構造で決まる。実質語 1 つに 8%、動詞 1 つに 4%、
接続詞の合成 1 つに 12%（宙に浮くと 4%）、熟語なら 15%。
長い・読みやすい・合成のある文ほど強い。

### 4. 接続詞の規則

接続詞は **直前の語に結合して 1 語**になる。`律` + `スル` → `律スル`。

| 接続詞 | 優先順位 | 結合できる語 |
| --- | --- | --- |
| サレタ / ワレタ | 1（述語・受身） | 浸食 改造 絆 催眠 破壊 ／ 失 救 |
| スル / セシ | 2（説明） | 爆発 貫通 分裂 回帰 追尾 律 破壊 ／ 呪縛 回避 思考 自律 |
| ノ / イ / ナ / ツ | 3（格） | 海 風 雷 炎 水 潮流 地 血 死 闇 光 呪イ 黄金 伝説 など |

規則は 2 つ。

1. **同じ接続詞は 1 文に 1 回まで。**
   NG「風ノ海ノ銃」… ノが 2 回なので**不成立**。
2. **優先順位は昇順。** 降順になったら**不成立**。
   NG「雷ノ浸食サレタ剣」… ノ（下位）がサレタ（上位）より先。
   OK「浸食サレタ雷ノ剣」… サレタ（上位）がノ（下位）より先。

| 例 | 結果 |
| --- | --- |
| `爆裂無双無敵疾風剣` | 成立（接続詞なし） |
| `律スル風ノ海神弓` | 成立。合成 `律スル` `風ノ` |
| `思考セシ天下無双ノ剣` | 成立。合成 `思考セシ`。`無双` は ノ と結べないため ノ は宙に浮く |
| `風ノ海ノ銃` | **不成立**（ノ 2 回） |
| `雷ノ浸食サレタ剣` | **不成立**（優先順位が逆） |
| `浸食サレタ雷ノ剣` | 成立 |

助詞（`の` `は` `が` …）と助動詞（`する` `なり` `べし`）は廃止した。
文をつなぐのは接続詞の役目になった。

### 5. プレイヤー自身も文にする

言葉鍛冶の一番上にある **自身の枠**。武器と同じく、末尾は **「人」** で固定。
`頑強` + `疾走` で **頑強疾走人** のように称号になり、文の力が**攻撃と防御**に効く。
並べ替えても末尾の「人」は動かない。

### 6. 戦闘中はいつでも組み替えられる

<kbd>Q</kbd> で **言葉鍛冶** を開きます。開いている間だけ時間が止まるので、
戦況を見てから並び替えられます。語をクリック → 枠をクリックで装着、
枠をクリックすると語袋へ戻ります。

### 7. ことばは戦闘中のレベルアップで獲得する

新しいことばはステージ終わりの報酬ではなく、**戦闘中のレベルアップ**で入ります。

| レベル | 入ってくるもの |
| --- | --- |
| ふつう | 語袋に 1 枚 |
| 5 の倍数 | 語袋に 2 枚 |
| 1 / 5 / 9 …（`4n+1`） | 自分自身の文の空き枠に 1 枚 |

語袋は 12 枚から始まり、8 レベルごとに 1 枚ずつ広くなります（上限 20）。
満杯のときは **一番古い 1 語** が消えてかわり、新しいことばが入ります。
引き直しボタンはありません。

### 8. クリア報酬

ステージを終えると **武器 / 武器強化 / 休息** から選べます。
武器レベルを 2 / 4 / 6 で上げると枠が 1 つずつ増えます。
強化できる武器と新しい武器が足りないときは、休息（体力回復）が入ります。
ことばはここでは出ません。すべて戦闘中のレベルアップで入手します。

### 9. 経験値の引き寄せ

敵を倒すと経験値が落ち、近づくと引き寄せられます（拾いに行く必要はない）。
遠いところにあるものも **時間切れでは消えません**。
引き寄せは速度に上限があるので、通り過ぎたり振動したりしません。

## 操作

| | |
| --- | --- |
| <kbd>WASD</kbd> / <kbd>矢印</kbd> | 移動 |
| <kbd>スペース</kbd> | **押しっぱなしでダッシュ**（スタミナを消費） |
| <kbd>Q</kbd> | 言葉鍛冶の開閉 |
| <kbd>Esc</kbd> | 一時停止 / 閉じる |
| タッチ | 画面を長押ししてからドラッグで移動 |

ダッシュは移動速度の 3.1 倍。毎秒 34 のスタミナを消費し、
離れると毎秒 26 で回復する。敵を弾き飛ばす。

武器は**自動で攻撃**します。狙いも自動で最も近い敵に合わせます。

## 中身

| | |
| --- | --- |
| 語 | 347 語（属性 83 / 形態 31 / 効果 162 / 動詞 35 / 自身 28 / 接続 8） |
| 接続詞 | 8 種。結合元 42 語。合成で優先順位と 1 回制限を判定 |
| 敵 | 通常 10 種 + ボス 4 体 |
| ステージ | 6 面 |

文の判定は `js/data/words.js` の **DP による最長一致分割** で行っています。
合成語（`火球` など）は分割辞書に載せず、別表 `PHRASE_BONUS` で扱っています。
載せると `火` + `球` の連結が分割不能になってしまうためです。

```
  data/                words (辞書・文判定) / weapons / enemies / stages
  game/                run (1 ステージ) / combat / entities / weapon / stats
  ui/                  render (canvas) / hud / forge / reward / menus
test/
  words.test.js        辞書の健全性と文判定      2291 assertions
  sim.test.js          ヘッドレス完走シミュ      620 assertions
  browser.test.js      Chrome 実機テスト          112 assertions
  all.mjs              全部まとめて回す
  shot.mjs             スクリーンショット
```

## 動かす

ビルドは何も要らない。静的ファイルを配信するだけでよい。

```bash
npm start            # http://localhost:8099
```

そのまま `index.html` を file:// で開いても動作しますが、
ES modules の制約でローカルサーバ経由の方を推奨します。

## テスト

```bash
npm test             # 辞書 + シミュレーション + ブラウザ
npm run test:words   # 辞書の健全性・文の成立判定
npm run test:sim     # ヘッドレスで 1 ステージを最後まで回す
npm run test:browser # Chrome を起動して実際に操作する (要 Chrome)
```

ブラウザテストは Chrome DevTools プロトコルでページを開き、
コンソールエラーがないこと・不成文で武器が無効化されること・
報酬とセーブまで通ることを確認します。

## スクリーンショット

```bash
npm run shot -- title title.png 800
```
