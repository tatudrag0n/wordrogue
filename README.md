# ワードローグ / Wordrogue

> 言葉を組み合わせて武装する 2D ローグライク。
> **作った「文」が成立しなければ、その武器は無効になる。**

Vampire Survivors 系の放置アクションに、**日本語の文を組み立てる**仕組みを乗せたもの。
外部ライブラリなし・ビルド不要・画像ファイルなしの、依存ゼロのブラウザゲーム。

---

## 遊びかた

### 1. 文がそのまま武器の名前になる

武器には **枠** がある。枠に語を並べると、それがそのまま **武器名** になる。
核語は無い。武器レベルに応じて **4 → 7 枠**。

| 並べた語 | 武器名 | 結果 |
| --- | --- | --- |
| 刃 + 必殺 | `刃必殺剣` | **成立** — 斬撃 |
| 爆裂 + 無双 + 雷 | `爆裂無双雷剣` | **名文** — 爆発する雷の斬撃 |
| 炎 + 分裂 + 散弾 | `炎分裂散弾銃` | **名文** — 拡散して貫通する炎の弾 |
| 火 + 球 | `火球剣` | **名文** — 熟語「火球」ボーナス |
| 刃 + 剣 | `刃剣` | **不成文** — 実質語 1 つ。攻撃しない |
| 風 + ノ + 海潮 + ノ + 銃 | `風ノ海潮ノ銃` | **不成文** — ノが 2 回 |

**成立の判定は 2 つ。** 連結した文字列が

1. 辞書で**完全に分割できる**（例: `爆裂無双迅早剣` → `爆裂` / `無双` / `迅早` / `剣`）
2. **実質語（助詞でも助動詞でもない語）を 2 つ以上**含む

末尾語も実質語として数えるので、成立には **枠の側で実質語を 2 つ以上** 置く必要がある
（末尾語ぶん要求が 1 つ多い）。

**末尾語だけが攻撃を決める。** 途中に別の形態語を並べても攻撃は変わらず、
効果（貫通・巨大・分裂など）だけが加わる。
`刃` + `必殺` + `爆弾` は「刃必殺爆弾剣」で、この武器は**斬撃**のまま（爆発は付く）。

| 語 | 効果 | 語 | 効果 |
| --- | --- | --- | --- |
| 剣 刃 刀 太刀 | 斬撃 | 弾 矢 針 球 | 射撃 |
| 爆弾 彗星 | 爆弾 | 雷 雷神 | 連鎖 |
| 環 回転 | 軌道 | 鞭 嵐 | 薙ぎ |
| 壁 棘壁 | 城壁 | 光線 閃光 | 光線 |
| 銃 | 射撃 | 弓 環刃 | 射撃・還刃 |

### 2. 末尾の語は武器ごとに固定

武器名の**末尾の語**は枠の外に固定で付く。並べ替えても動かない。
だから**名前と攻撃の型が必ず一致する**。

| 武器 | 末尾語 | 攻撃 |
| --- | --- | --- |
| 剣 | `剣` | 斬撃 |
| 銃 | `銃` | 射撃 |
| 弓 | `弓` | 射撃 |
| 爆弾 | `爆弾` | 爆弾 |
| 回転刃 | `環` | 軌道 |
| 雷 | `雷` | 連鎖 |
| 鞭 | `鞭` | 薙ぎ |
| 棘壁 | `壁` | 城壁 |
| 環刃 | `環刃` | 還刃 |
| 光線 | `光線` | 光線 |

**末尾語だけが攻撃を決める。** 途中に別の形態語を並べても攻撃は変わらず、
効果（貫通・巨大・分裂など）だけが加わる。
`刃` + `必殺` + `爆弾` は「刃必殺爆弾剣」で、この武器は**斬撃のまま**（爆発は付く）。

### 3. 語の種類

| 種別 | 例 | 効果 |
| --- | --- | --- |
| 属性 | 火 灼熱 猛毒 | 色と状態異常（炎上・減速・感電・毒） |
| 形態 | 剣 銃 弓 弾 矢 球 環 壁 | 効果と末尾語になる。**攻撃は末尾語だけ** |
| 効果 | 巨大 貫通 分裂 散弾 | 数値を上げる |
| 動詞 | 燃える 貫く 凍る 爆裂 | 1 個で 1 つの動作になる |
| 接続 | スル ノ サレタ イ | **直前の語に結合する**（次項） |
| 自身 | 頑強 疾走 護符 | プレイヤーに効く |


**文の力**は構造で決まる。実質語 1 つに 8%、動詞 1 つに 4%、
接続詞の合成 1 つに 12%（宙に浮くと 4%）、熟語なら 15%。
長い・読みやすい・合成のある文ほど強い。

### 4. 接続詞の規則

接続詞は **直前の語に結合して 1 語**になる。`律` + `スル` → `律スル`。

| 接続詞 | 優先順位 | 結合できる語 |
| --- | --- | --- |
| サレタ / ワレタ / ラレタ / ク / ナ | 1（述語・受身・断定） | 改造 催眠 分裂 貫通 凍結 撃退 束縛 ／ 張 撃 縛 封 ／ 律 思考 回帰 |
| スル / セシ / リ | 2（説明） | 爆発 貫通 分裂 追尾 律 破壊 精神 侵入 ／ 思考 自律 回避 心眼 |
| ノ / イ / ツ / ニ / ヲ / ヘ | 3（格・接尾・方向） | 属性・形態・自身の語すべて（`ノ`）／ 鋭利 剛硬 迅早 巧 ／ 刃 弾 矢 剣 ／ 火 雷 風 闇 |

**接続詞は 14 種類**。すべて片仮名で、漢字語のあいだに挟むと
`鋭イ剣` `強ク張ラレタ弓` `改造サレタ銃` のようにリズムが生まれる。

結合元は **300 語**（語彙 376 語の 80%）。語を増やしても重みは 14 倍のままなので、
**実際に引くと約 10%** で出る。語彙が増えても出現率が下がり続けないようにしている。

規則は 2 つ。

1. **同じ接続詞は 1 文に 1 回まで。**
   NG「風ノ海潮ノ銃」… ノが 2 回なので**不成立**。
2. **優先順位は昇順。** 降順になったら**不成立**。
   NG「雷ノ浸食サレタ剣」… ノ（下位）がサレタ（上位）より先。
   OK「浸食サレタ雷ノ剣」… サレタ（上位）がノ（下位）より先。

| 例 | 結果 |
| --- | --- |
| `鋭イ剣` | **名文**。合成 `鋭イ` |
| `強ク張ラレタ弓` | **名文**。合成 `強ク` `張ラレタ` |
| `改造サレタ銃` | **名文**。合成 `改造サレタ` |
| `爆裂無双無敵疾風剣` | 成立（接続詞なし） |
| `律スル風ノ海潮神弓` | 成立。合成 `律スル` `風ノ` |
| `風ノ海潮ノ銃` | **不成立**（ノ 2 回） |
| `雷ノ浸食サレタ剣` | **不成立**（優先順位が逆） |
| `浸食サレタ雷ノ剣` | 成立 |

助詞（`の` `は` `が` …）と助動詞（`する` `なり` `べし`）は廃止した。
文をつなぐのは接続詞の役目になった。

### 5. プレイヤー自身も文にする

言葉鍛冶の一番上にある **自身の枠**。武器と同じく、末尾は **「人」** で固定。
`頑強` + `疾走` で **頑強疾走人** のように称号になり、文の力が**攻撃と防御**に効く。
並べ替えても末尾の「人」は動かない。

### 6. 戦闘中はいつでも組み替えられる

<kbd>Q</kbd> で **言葉鍛冶** を開きます。開いている間だけ時間が止まるので、
戦況を見てから並び替えられます。

語は **ドラッグして枠へ運ぶ** と装着でき、**語どうし / 枠どうし / 語彙とのあいだ**を
入れ替えられます。語 ↔ 枠 / 枠 ↔ 枠の入れ替えでは、どちらの語も消えません。
クリックで選んでから枠をクリックする手順も残しています（タッチ端末向け）。

| ドロップ | 結果 |
| --- | --- |
| 語彙 → 枠 | 装着。語彙の空きが 1 つ減る |
| 枠 → 語彙 | 語彙へ戻す。**満杯ならできない** |
| 枠 ⇄ 枠 | 入れ替え。語は消えない |
| 語彙 ⇄ 語彙 | 入れ替え。語は消えない |

末尾語（`剣` `銃` `弓` …）は枠の外に固定なので、ドラッグの対象外です。

### 7. ことばは戦闘中のレベルアップの 3 択で獲得する

新しいことばはステージ終わりの報酬ではなく、**戦闘中のレベルアップ**で入ります。

| レベル | 入ってくるもの |
| --- | --- |
| ふつう | 語彙に **3 択 1 個** |
| 5 の倍数 | 語彙に **3 択が 2 回**（順に選ぶ） |
| 1 / 5 / 9 …（`4n+1`） | 自分自身の文の空き枠に 1 個（自動で入る） |

3 択は **7 秒**。時間切れになると上の候補から 1 個入ります。**時間は止まりません。**
画面に出た 3 択を選ぶと次の 3 択が出ます（5 の倍数の 2 回分）。

### 8. 満杯のときは「捨てることば」を自分で選ぶ

語彙が満杯だと新しいことばが入りません。このときは先に **捨てることば** を 1 つ決めます。
語彙の一覧が全部出るので、消していい語を選んだあとで 3 択に進めます。

選ばずに時間切れになると **一番古い 1 語** が消えます。
また、**満杯のときは武器や自身の文から語を外せません**（空きを作ってから）。

語彙は **12 個**から始まり、ステージ終わりに報酬で選べる **言玉** で 1 個ずつ広がります。
**上限 30**、増やした分は **次のステージへ持ち越し**ます。引き直しボタンはありません。

開始時の 10 個は **漢字だけの短い語**（平均 1.5 文字、かな 0%）。
漢字語と片仮名の接続詞を交互に並べて、リズムのある武器名を作れるようにしている。
`火弾剣` や `業火弾ノ球剣`、`鋭イ剣`、`強ク張ラレタ弓` のような名前。
かなの動詞（`燃える` `斬る` など）は出る確率を 1/4 に下げてある。

語彙が満杯で 3 択を出すとき、**捨てる語は候補と重複しないものだけ**を選ぶ。

### 9. 「忘れる」で空きを作る

言葉鍛冶の **「忘れる」** を押すとモードが点ります。このときは語彙の語をクリックするだけで
**捨てられます**。武器や自身の文にある語は対象外です（それらは「忘れられない」）。

### 10. クリア報酬

ステージを終えると **武器 / 武器強化 / 言玉 / 休息** から選べます。
武器レベルを 2 / 4 / 6 で上げると枠が 1 つずつ増えます。
言玉は語彙の容量を 1 個広げ、次のステージへ持ち越します。
強化できる武器と新しい武器が足りないときは、休息（体力回復）が入ります。
ことばはここでは出ません。すべて戦闘中のレベルアップで入手します。

### 11. 辞書

使えるすべてのことばを一覧できます。カテゴリで絞り込んだり名前で検索したりできます。
開いている間は時間が止まります。

| | 開き方 |
| --- | --- |
| 戦闘中 | HUD の **「辞」** ボタン |
| 言葉鍛冶 | 鍛冶の **「辞書」** ボタン |

言葉鍛冶の上から開いても **鍛冶は閉じません**。閉じると元の画面（鍛冶）に戻るので、
語を組み立てた状態のまま意味を調べられます。
なお語を<strong>クリック</strong>しただけでも、鍛冶の下にその語の効果が出ます。

### 12. 敵も「文」でできている

敵の頭の上には **敵自身の文** が出ています。通常の敵は 2 語、ボスは 3 〜 5 語。
自分が作った武器の文で、その語を **斬り落とします**。

| 武器の文 | 斬る量 | 確率 |
| --- | --- | --- |
| 成立 | 1 語 | 15% |
| 熟語を含む | 2 語 | 45% |
| 述語（接続詞の合成）がある | 2 語 | 45% |
| 不成文 | 斬れない | — |

敵の文が **不成文** になると頭の上に「不成文」と出て、その敵は
**動かなくなり、ダメージの受けが 2.5 倍** になります。ボスは倒れません。
崩しても攻撃パターンが止まるだけです（0.3 倍の確率でしか斬り切れない）。

つまり **よく組んだ文ほど、敵の文を早く崩せる**。
威力で押し切るのとは別の、ことばの作り方で勝つ道があります。

### 14. 書庫 — 走った分が、次の走りに残る

ステージをクリアすると **墨**（書庫の通貨）が手に入ります。
**敵の文を崩す**ときにも貯まります（行動が止まるぶん強いので多く付きます）。

| 入手 | 墨 |
| --- | --- |
| ステージクリア | 20 + ステージ番号 × 12 |
| 敵の文を崩す | 2 / 体 + さらに 2 につき 1 |

累計はタイトル画面の **「文を崩した数」** に出ます。

書庫では次の 2 種類が買えます。

- **恒久強化** … 体力 / 攻撃 / 装甲 / 経験値 / 引き寄せ / 会心。各 6 〜 10 段階。
  段階を上げるほど値段が上がるので、使い切りはできない。
  保存は最終値で `stats.js` の `resolvePlayerStats` がそのまま読む。
- **恒久の語** … 買った語は **毎回ランの最初から語彙に入る**。

どちらも次のランに持ち越す。死んでも失わない。

### 15. 経験値の引き寄せ

敵を倒すと経験値が落ち、近づくと引き寄せられます（拾いに行く必要はない）。
遠いところにあるものも **時間切れでは消えません**。
引き寄せは速度に上限があるので、通り過ぎたり振動したりしません。

## 操作

| | |
| --- | --- |
| <kbd>WASD</kbd> / <kbd>矢印</kbd> | 移動 |
| <kbd>スペース</kbd> | **押しっぱなしでダッシュ**（スタミナを消費） |
| <kbd>Q</kbd> | 言葉鍛冶の開閉 |
| <kbd>Esc</kbd> | 一時停止 / 閉じる |
| タッチ | 画面を長押ししてからドラッグで移動 |

ダッシュは移動速度の 3.1 倍。毎秒 34 のスタミナを消費し、
離れると毎秒 26 で回復する。敵を弾き飛ばす。

武器は**自動で攻撃**します。狙いも自動で最も近い敵に合わせます。

## 動かす

ビルドは何も要らない。静的ファイルを配信するだけでよい。

```bash
npm start            # http://localhost:8099
```

そのまま `index.html` を file:// で開いても動作しますが、
ES modules の制約でローカルサーバ経由の方を推奨します。

## テスト

```bash
npm test             # 辞書 + シミュレーション + ブラウザ
npm run test:words   # 辞書の健全性・文の成立判定
npm run test:sim     # ヘッドレスで 1 ステージを最後まで回す
npm run test:browser # Chrome を起動して実際に操作する (要 Chrome)
```

ブラウザテストは Chrome DevTools プロトコルでページを開き、
コンソールエラーがないこと・不成文で武器が無効化されること・
報酬とセーブまで通ることを確認します。

## スクリーンショット

```bash
npm run shot -- title title.png 800
```
