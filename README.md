# ワードローグ / Wordrogue

> 言葉を組み合わせて武装する 2D ローグライク。
> **作った「文」が成立しなければ、その武器は無効になる。**

Vampire Survivors 系の放置アクションに、**日本語の文を組み立てる**仕組みを乗せたもの。
外部ライブラリなし・ビルド不要・画像ファイルなしの、依存ゼロのブラウザゲーム。

---

## 遊びかた

### 1. 文がそのまま武器の名前になる

武器は **10 文字までの文** です。文の並びは枠に嵌めず、**語を自由にドラッグして並べます**。
並べた語と接続詞がそのまま **武器名** になります。武器レベルでは文の長さは変わりません。

| 並べた語 | 武器名 | 結果 |
| --- | --- | --- |
| 焔 + 必 + 剣 | `焔必剣` | **成立** — 斬撃 |
| 焔 + を + 斬 + された + 硬 | `焔を斬された硬` | **絶句** — 日本語として完成 |
| 焔 + の + 爆裂 + する + 妙 + な + 刃 | `焔の爆裂する妙な刃` | **絶句** — 最長 |
| 焔 + 刃 | `焔刃` | **名文** — 熟語「焔刃」ボーナス |
| 刃 + 弾 | `刃弾` | **不成文** — 武器語どうしは隣り合えない |
| 風 + の + 潮 + の + 銃 | `風の潮の銃` | **不成文** — のが 2 回 |

**成立の判定は 2 つ。** 連結した文字列が

1. 辞書で**完全に分割できる**（例: `焔の爆裂する妙な刃` → `焔` / `の` / `爆裂` / `する` / `妙` / `な` / `刃`）
2. **実質語（接続詞でない語）を 2 つ以上**含む

**文の中の武器語が攻撃を決める。** 武器語（剣・弾・環…）は自動で付かず、
語として得るものです（次項）。文の後方から最初に見つかった武器語が攻撃を決めます。
武器語が文に無いときは、その武器の既定の型（剣なら斬撃、銃なら射撃…）になります。

| 語 | 効果 | 語 | 効果 |
| --- | --- | --- | --- |
| 刃 剣 刀 斧 戈 牙 爪 | 斬撃 | 銃 玉 矢 針 弓 槍 矛 球 | 射撃 |
| 珠 還 | 還り刃 | 雷 | 連鎖 |
| 弾 塊 岩 石 | 爆弾 | 光 | 光線 |
| 環 輪 | 軌道 | 鞭 鎖 | 薙ぎ |
| 壁 網 盾 | 城壁 | | |

武器語どうしは隣り合えません（`刃弾` は日本語に無いので不成立）。
語を 1 つ挟めば `焔刃弾` のように成立します。

### 2. 武器語は戦闘中に得る

武器語（剣・刃・弾・環・壁…）は語彙から引かれません。
**レベルアップの 3 択**に出ます（他の語より確率が低い）。
得た武器語は

- いまの武器の文に置けば、その**攻撃の型が変わる**
- そのまま**新しい武器の文**になる（武器は最大 3 つ）

 weapon 語を得たときは「新しい文を作れる」ので、武器の数は 1 つずつ増えます。
最初から持てる武器は **1 つだけ**。武器語 得ているたびに 2 つ目、3 つ目ができます。

### 3. 語の種類

| 種別 | 例 | 効果 |
| --- | --- | --- |
| 属性 | 火 焔 猛 | 色と状態異常（炎上・減・感・毒） |
| 形態 | 剣 銃 弓 弾 矢 球 環 壁 | **武器語**。文に置くと攻撃の型を決める。語彙からは引かれず、3 択で得る |
| 効果 | 巨 貫 裂 散 | 数値を上げる |
| 動詞 | 燃 貫 凍 爆裂 | 1 個で 1 つの動作になる |
| 接続 | する の された い | **直前の語に結合する**（次項）。3 択には出ない。語の横で切り替える |
| 自身 | 頑 走 符 | プレイヤーに効く |


**文の力**は「日本語としての自然さと完成度」で決まる。
`1 + 実質語数 Bonus + 自然さ × 0.30`。
属性で始まり、格・連体・述語がある文ほど強い。
長いから強い、ではなく **自然だから強い**。

### 4. 接続詞は語の横。タップで切り替える

接続詞は **その語の直後**に付きます。別の置き場ではないので、
接続詞を足しても文の長さは 1 文字分増えるだけです。

```
  焔  を  斬  された  妙  な  刃
       接続詞は「その語の直後」
```

文の中の**語をタップすると、直後の接続詞が切り替わります**。
その語に結合できる接続詞だけが候補になり（品詞で判定）、
一周すると**接続詞なし**になり、また先頭から回ります。

**語の右にある接続詞のマスをタップすると一覧が出て、使える接続詞を一発で選べます。**
順に回すのがタップ、選び直すのが一覧です。まちがえたら **「戻す」** で 1 つ前に戻せます。

- `発` → `する`（する）→ `の`（の）→ `に` → `を` → `へ` → **無し**
- `爆` → `せし`（ぜし）→ `る`（ぜる）→ … → **無し**
- `回` → `る`（まわる）→ `り`（まわり）→ `せし`（回す）→ … → **無し**
- `急` → `く`（きゅうく）→ `い`（せいかい）→ `な`（急な）→ `に`（急に）→ **無し**

**語 2 つに接続詞 2 つで `焔を斬る` のように、完成した文が基本**になります。

結合の相性は **品詞** で決まる。語は 5 つの品詞に分かれる。
**日本語の区別どおり**に分けるので、結合できる語だけが表示される。

| 品詞 | 例 | 付く接続詞 |
| --- | --- | --- |
| 体言（名詞） | `焔` `刃` `必` `頑` `潮` | の・を・に・へ |
| する-体言 | `爆裂` `貫` `蝕` `侵` `導` `圧` `徹` | の・を・に・へ・**する** |
| 形容（い形容） | `硬` `鋭` `速` `強` `淡` `寂` `小` `大` `急` `通` `冷` `重` | **く・い** |
| 形動（な形容） | `妙` `急` | **な・に** |
| 「〜か」のな形容 | `静` `確` `滑` `適` `華` `豪` `精` `良` `明` `優` `巧` | **かな** |
| 用言（動詞） | `斬` `貫` `焼` `凍` `回` `響` | る・された・われた・られた・せし・り・を・に |
| 用言 + 動詞の形 | `蝕` `踏` `掴`（〜む）／`溶` `凍` `潰`（〜ける）／`察`（する） | **む・ける・する** |

い形容詞と な形容詞 を混ぜないことが要点。
`速` は `速く` `速い` に、`妙` は `妙な` `妙に` にしか付かない。
`速な` `妙い` のような混ざり方は作れない。
**な形容詞は「X な」が日本語として成る語だけ**にする。
1 漢字で直接付くのは `急な` `妙な` の 2 語。
`静かな` `確かな` `滑らかな` のように **1 漢字語からは作れないものは、
接続詞 `かな`（`〜か` の連体形）で書く**。
`静` + `かな` → 静かな刃（静かな刃）、`確` + `かな` → 確かな刃（確かな刃）、
`滑` + `かな` → 滑かな刃（滑らかな刃）。
`静な` `剛な` `豪な` `精な` `滑な` は 1 漢字からは日本語に無いので作らない。
`静` `剛` `豪` `精` `滑` `密` などは**名詞・接尾語**として扱う（接続詞は の・を・に・へ・かな）。
`巨` と `大` を並べれば「巨大な刃」になる。
（`急` だけは例外で、い形容の語幹であり な形容にも使うので `急く` `急い` `急な` `急に` が全部付く。）

**語幹が「〜か」になる語には `かな` が付く**（11 語）。
`静か` `確か` `滑らか` `適切` `華美` `豪快` `精密` `良質` `明快` `優美` `巧妙`。
語幹が「〜か」にならない な形容詞には付かない：`強かな`（強固）`頑かな`（頑強）`神かな`（神速）は無い。

**1 漢字語どうしの連結は な形容詞にしない。**
`華麗` `精密` `端正` `頑強` `神速` を置くと、`華` と `麗` を並べた文が
分割で `華麗` になって効果と品詞が別物になる。だから `華` `麗` は別の語のまま扱う。

語は効果語（`血` `瞬` `導` `回`…）の表に書かれていても、
**文法上の品詞は語表で決めている**。効果語だから名詞、ということはない。

- `小` `大` `通` `冷` `急` `重` … 効果語だが **い形容詞** → `小く` `通い` `冷つ`
- `回` … 効果語だが **動詞** → `回る`（回る）`回り`（回り）`回せし`（回す）
- `妙` `急` … **な形容詞** → `妙な` `急な`
- `静` `確` `滑` `適` … 効果語だが **体言**。静か / 確か / 滑らか の連体形は接続詞 `かな` → `静かな刃`
- `爆` `貫` `侵` … **する-体言** → `爆する`（爆する）
- `巨` `静` `剛` `豪` … 効果語だが **名詞・接尾語** → `巨の` `静の`。
  な形容詞は「巨大」であって「巨」ではない。`巨な` `静な` は日本語に無いので作らない
  （静かな刃 は `静` + `かな` で作る）

**日本語にこの並びが無いものは作らない。** そのため
`急く` のあとに名詞は置けない（連用形は名詞を修飾しない）ので、
`急く斬る妙な刃` のように **あとに動詞** を置く。`急く焔を斬る刃` は不成立。

**語彙から引ける語は、かならずどれかの接続詞に自然に付く。**
行き止まりの語は無い。武器語（剣・銃・環など）は語彙からは引かれない。

さらに接続詞には語ごとの絞り込み・例外がある。

| 接続詞 | 付く語 | 補足 |
| --- | --- | --- |
| `する` | する-体言 + `〜する` が動詞の語（`察`） | `爆裂する` ✓ / `察する` ✓ / `焔する` ✗ |
| `む`（終止形・命令形「〜む」） | `蝕` `踏` `挟` `掴` `嚇` `沈` `縮` `潜` だけ | `蝕む` ✓ / `踏む` ✓ / `斬む` ✗ / `溶む` ✗ |
| `ける`（上一段「〜ける」） | `溶` `凍` `融` `焼` `焦` `砕` `潰` `冷` だけ | `溶ける` ✓ / `凍ける` ✓ / `斬ける` ✗ / `響ける` ✗ |
| `つ`（付言便乗 連用形＋つ） | `温` `冷` `厚` `泡` `重` だけ | 温＋つ ✓ / 強＋つ ✗ |
| `く`（連用形「〜く」） | い形容詞 +「〜く」で連用形・連体形になる語（`響` `沸` `吐` `穿` `融` `散` `瞬` `貫` `焼` `叩` `浮` `溶` `跨` `轟` `裂` `砕`） | `速く` ✓ / `響く` ✓ / `貫く` ✓ / `斬く` ✗ |
| `な` `に` | な形容詞（`妙` `急` だけ） | `妙な` ✓ / `急な` ✓ / `静な` ✗ / `強な` ✗ |
| `かな`（`〜か` の連体形） | 語幹が「〜か」になる語（`静` `確` `滑` `適` `華` `豪` `精` `良` `明` `優` `巧`） | `静かな` ✓ / `滑かな` ✓ / `静な` ✗ / `焔かな` ✗ / `強かな` ✗ |

`く` の例外は日本語に「〜く」で連用形になる語だけ。
`響` `沸` `吐` `穿` `融` `散` `瞬` `貫` `焼` `叩` `浮` `溶` `跨` `轟` `裂` `砕`（+ い形容詞全部）。
この 16 語の「〜く」は**終止形・連体形**でもあるので、あとに名詞を置ける
（`貫く刃` `雷の響く刃`）。
い形容詞の連用形（`速く`）は名詞を修飾しないので、あとに名詞は置けない（`速く剣` ✗）。

| 接続詞 | 付く直前の語 | 強さの目安 | 意味 | 名詞を修飾 |
| --- | --- | --- | --- | --- |
| された / われた / られた | 用言 | 1 | `〜された` `〜われた` `〜られる` | ○ |
| る | 用言 | 1 | `〜る` | ○ |
| く | 形容（+ `響` `沸` `吐` `穿` `融` `散` `瞬` `貫` `焼` `叩` `浮` `溶` `跨` `轟` `裂` `砕`） | 1 | `〜く` | ×（動詞の「〜く」は ○） |
| な | 形動（+`急`） | 1 | `〜な` | ○ |
| い | 形容 | 1 | `〜い` | ○ |
| する | 体言（する-体言） | 2 | `〜する` | ○ |
| せし / り | 用言 | 2 | `〜し` `〜り` | × |
| の / へ | 体言 | 3 | `〜の` `〜へ` | ○ |
| つ | 付言便乗の語 | 3 | `〜つい` | ○ |
| に / を | 体言・用言 | 3 | `〜に` `〜を` | ○ |
| へ | 体言 | 3 | `〜へ` | ○ |
| に（形動に付く） | 形動（`妙` `急`） | 3 | `〜に`（妙に / 急に） | × |
| かな | `静` `確` `滑` `適` `華` `豪` `精` `良` `明` `優` `巧` | 1 | 静か / 確か の連体形（`静かな` `確かな`） | ○ |
| む | `蝕` `踏` `挟` `掴` `嚇` `沈` `縮` `潜` | 2 | `〜む`（`蝕む` `踏む`） | ○ |
| ける | `溶` `凍` `融` `焼` `焦` `砕` `潰` `冷` | 2 | `〜ける`（`溶ける刃`） | ○ |

**接続詞は 18 種類**。すべてひらがなで、漢字語のあいだに挟むと
`焔を` `斬る` `硬い` のように文の骨組みが生まれる。

文が壊れるのは次の 4 つだけ。

1. **同じ接続詞を 2 回使わない。**
   NG「風の潮の銃」… のが 2 回なので**不成立**。
2. **接続詞どうしを隣接させない。**
   「毒の蝕する針」(の→する) も「蝕する毒の針」(する→の) も成立する。
   順序はどちらでもよい。NG「焔するの剣」… 接続詞の連続は宙に浮く。
3. **接続詞は直前の語に結合できなければならない。** 宙に浮くと**不成立**。
   NG「妙された刃」… `された` は用言にしか付かない。
   NG「焔く硬剣」  … `く` はい形容と、「〜く」で連用形になる語にしか付かない。
   NG「速な剣」      … `な` は な形容にしか付かない。
   NG「焔する剣」  … `する` は する-体言にしか付かない。
   NG「強つい剣」    … `つ` は付言便乗の語にしか付かない。
4. **接続詞のあとに名詞が来るなら、その接続詞は連体形でなければならない。**
   NG「焔を斬く剣」… 連用形は名詞を修飾しない。
   NG「焔の妙に剣」… 連用形「〜に」（妙に）も名詞を修飾しない。
   NG「焔を妙刃」  … `を` の後ろに動詞（目的語）が要る。
   NG「刃剣」        … 形を表す語どうしの重複。

この 4 つに当たらなくても、**武器語どうしが隣り合うと不成立**になる（`刃弾` など）。
語を 1 つ挟めば `焔刃弾` のように通ります。

| 例 | 文 | 結果 |
| --- | --- | --- |
| `焔を斬された妙な剣` | 焔 を 斬 された 妙 な | **絶句**。日本語として完成 |
| `焔を斬る妙な剣` | 焔 を 斬 る 妙 な | **絶句**。最長 |
| `焔速く斬る硬剣` | 焔 の 速 く 斬 る 硬 | **絶句** |
| `雷の響く斬る剣` | 雷 の 響 く 斬 る | **絶句**。「〜く」で連用形になる語にも `く` が付く |
| `雷の響く刃` | 雷 の 響 く | **成立**。動詞の「〜く」は連体形なので名詞を修飾できる |
| `急く斬る妙な刃` | 急 く 斬 る 妙 な | **成立**。急く斬る妙な刃 |
| `焔を斬る静かな刃` | 焔 を 斬 る 静 かな | **成立**。静か の連体形は `かな` で書く |
| `静かな焔を斬る刃` | 静 かな 焔 を 斬 る | **成立**。静か な焔を斬る刃 |
| `焔を斬る確かな刃` | 焔 を 斬 る 確 かな | **成立**。確かな刃 |
| `滑かな毒を斬る刃` | 滑 かな 毒 を 斬 る | **成立**。滑らかな毒を斬る刃 |
| `踏む焔を斬る刃` | 踏 む 焔 を 斬 る | **成立**。踏む焔を斬る刃 |
| `溶ける霜を斬る刃` | 溶 ける 霜 を 斬 る | **成立**。溶ける霜を斬る刃 |
| `霜を蝕む刃` | 霜 を 蝕 む 刃 | **成立**。霜を蝕む刃 |
| `察する毒を斬る刃` | 察 する 毒 を 斬 る | **成立**。察する毒を斬る刃 |
| `急な焔を斬る刃` | 急 な 焔 を 斬 る | **成立**。急な焔を斬る刃 |
| `導する毒を斬る刃` | 導 する 毒 を 斬 る | **成立**。導する毒を斬る刃 |
| `毒を回せし妙な刃` | 毒 を 回 せし 妙 な | **成立**。毒を回す妙な刃 |
| `焔を貫く刃` | 焔 を 貫 く | **成立**。動詞の「〜く」は連体形なので名詞を修飾できる |
| `呪いの刃` | 呪 い の | **成立**。`呪` + `い` で 呪い（名詞）ができる |
| `呪いを斬る刃` | 呪 い を 斬 る | **成立**。`い` で作った名詞は格（を）も取れる |
| `焔を斬る剣` | 焔 を 斬 る | **絶句** |
| `焔を斬る硬剣` | 焔 を 斬 る 硬 | **絶句**。い形容詞の語幹複合も一続きの名詞になる |
| `焔に妙に斬る剣` | 焔 に 妙 に 斬 る | **不成立**（`に` は 1 文に 1 回まで。格でも連用でも同じ接続詞） |
| `焔の爆裂する妙な剣` | 焔 の 爆裂 する 妙 な | **絶句**。する-体言まで放入 |
| `焔を斬された刃剣` | 焔 を 斬 された 刃 | **不成立**（`刃剣` は日本語に無い） |
| `焔を斬された速な剣` | 焔 を 斬 された 速 な | **不成立**（い形容に「な」は無い） |
| `強かな毒を斬る刃` | 強 かな 毒 を 斬 る | **不成立**（`強か` は無い。強固 の語幹ではない） |
| `焔かなを斬る刃` | 焔 かな を 斬 る | **不成立**（`焔か` は無い） |
| `焔を斬る溶む刃` | 焔 を 斬 る 溶 む | **不成立**（`溶む` は無い。`溶ける`） |
| `焔を斬る斬ける刃` | 焔 を 斬 る 斬 ける | **不成立**（`斬ける` は無い） |
| `妙された刃剣` | 妙 された 刃 | **不成立**（`された` に結べない） |
| `焔を妙刃` | 焔 を 妙 | **不成立**（`を` の後ろに動詞が無い） |
| `焔く硬剣` | 焔 く 硬 | **不成立**（`く` はい形容と「〜く」の語のみ） |
| `焔する硬剣` | 焔 する 硬 | **不成立**（`する` はする-体言のみ） |
| `強つい硬剣` | 強 つ 硬 | **不成立**（`つ` は付言便乗の語のみ） |
| `風の潮の銃` | 風 の 潮 の | **不成立**（の 2 回） |

**自然さと完成度が、そのまま文の力になる**（`文の力 = 1 + 実質語のボーナス + 自然さ × 0.30`）。
属性で始まり・格があり・連体があり・述語があって、文が閉じているほど強い。
羅列（修飾のあいだに係り結びが無いまま語が 4 つ以上並ぶ）や、形・動詞で始まる文は減点される。

**「〜の」と「〜する」が同じ名詞に掛かる並びは減点する。**
`創する毒の剣`（創する毒の剣）は自然、`毒の創する剣`（毒の創する剣）は不自然。
前者は連体節が内側に入り、後者は格と連体節が同じ名詞に重なって係り損ねる。

| 項 | 加点 |
| --- | --- |
| 属性で始まる | +1.2 |
| 句切 `〜の` `〜へ` | +0.55 / 個 |
| 形容の連体 `〜い` `〜な` | +0.5 / 個 |
| 動作（動詞） | +0.4 |
| 述語（`〜る` `〜された`） | +0.6 |
| 目的語（`〜を`） | +0.7 |
| 熟語（3 字以上） | +0.7 |
| 形で始まる | −0.8 |
| 効果で始まる | −0.3 |
| 動詞で始まる | −0.4 |
| 4 語が羅列 | −0.45 / 語（4 語目から） |
| 述語の後ろに修飾句がぶら下がる | −0.5 |
| 格句と連体節が同じ名詞に重なる | −0.5 |

### 5. プレイヤー自身も文にする

言葉鍛冶の一番上にある **自身の文**。武器と同じく自由に並べられます。
末尾だけは **「人」** が文の外に固定で付きます。
`頑` + `走` で **頑走人** のように称号になり、文の力が**攻撃と防御**に効く。
並べ替えても末尾の「人」は動きません（`人` は文の長さにも数えます）。

### 6. 戦闘中はいつでも組み替えられる

<kbd>Q</kbd> で **言葉鍛冶** を開きます。開いている間だけ時間が止まるので、
戦況を見てから並び替えられます。

語は **語彙から文の隙間（＋）へドラッグ** すると並びに入ります。
文の中の語もドラッグで並べ替えられます。どちらの語も消えません。

**タップだけで組むこともできます。** ドラッグに向かない端末向け。

| 手順 | 結果 |
| --- | --- |
| 語彙の語を **タップ** | 語を持ち上げる（選択される） |
| 持ち上げた状態で **文の隙間をタップ** | そこに並べる |
| 持ち上げた状態で **語彙をタップ** | 文から語彙へ戻す |
| 文の語の **✕ をタップ** | 文から語彙へ戻す（いちばん確実） |
| 文の語を **タップ** | 直後の接続詞が順に切り替わる（一周で無し） |
| 文の語の **右の接続詞マスをタップ** | 使える接続詞の一覧から一発で選ぶ |
| **「戻す」ボタン** | 直前の操作を 1 つ取り消す（最大 40 回） |
| 文の語を **長押し** | 語を持ち上げて、以降はタップだけで配置できる |

持ち上げているときは対象が光ります。同じ語をもう一度タップすると元に戻ります。

**語彙が満杯でも外せます。** 戻すときは語彙で**最も古い 1 語が捨てられます**
（語を得るときの「古い語から捨てる」と同じ規則）。自分で選びたいときは
「忘れる」で空きを作ってから戻してください。

| ドロップ | 結果 |
| --- | --- |
| 語彙 → 文 | 並べる。語彙の空きが 1 つ減る |
| 文 → 文 | 並びを変える。語は消えない（最後の隙間へ落としたら末尾に来る） |
| 文 → 語彙 | 語彙の空きへ戻す。**満杯なら最古の 1 語を捨てる**（落としたマスが埋まっていても戻す） |
| 文 → 自身の文 | 移す。10 文字に収まるときだけ |
| 語彙 ⇄ 語彙 | 何もしない（語は消えない） |

ドラッグの判定は **7px**。それより動かなければ通常のタップとして扱います。
文の中の語は 7px 動くまでタップ（接続詞の切り替え）として扱われるので、
並べ替えたいときは **長押し** してから動かします。
接続詞を選び直すときは、語の右のマスをタップして一覧から選ぶのが早いです。

### 7. ことばは戦闘中のレベルアップの 3 択で獲得する

新しいことばはステージ終わりの報酬ではなく、**戦闘中のレベルアップ**で入ります。
**接続詞は 3 択に出ない**（語の横で切り替えるだけだから）。
**武器語は出にくい**（確率 22%・第 1 候補だけ）。武器語を得ると武器が 1 つ増えます（最大 3 つ）。

| レベル | 入ってくるもの |
| --- | --- |
| ふつう | 語彙に **3 択 1 個**（そのうち稀に武器語。得れば新しい武器） |
| 5 の倍数 | 語彙に **3 択が 2 回**（順に選ぶ） |
| 1 / 5 / 9 …（`4n+1`） | 自分自身の文に 1 個（自動で入る。10 文字に収まるとき） |

3 択は **7 秒**。時間切れになると上の候補から 1 個入ります。**時間は止まりません。**
画面に出た 3 択を選ぶと次の 3 択が出ます（5 の倍数の 2 回分）。

### 8. 満杯のときは「捨てることば」を自分で選ぶ

語彙が満杯だと新しいことばが入りません。このときは先に **捨てることば** を 1 つ決めます。
語彙の一覧が全部出るので、消していい語を選んだあとで 3 択に進めます。

選ばずに時間切れになると **一番古い 1 語** が消えます。
また、**満杯のときは武器や自身の文から語を外せません**（空きを作ってから）。

語彙は **12 個**から始まります。**書庫の言玉**で 1 個ずつ広げられます（恒久強化「語彙」）。
**上限 30**、増やした分は **次のステージへ持ち越し**ます。引き直しボタンはありません。

語は創作的な固有名詞を避けた。**「太陽を焼く剣」「雷を貫く針」のように、そのままで意味が通る語**だけを使う。
効果語も「威力」「速攻」「防御」のように、その語が何を表すのかひと目でわかるものに限った。
属性語も「炭火」「夜」「金属」のような基本的な語に寄せた。造語（獄炎・妖刀・鋼鉄など）は置いていない。

開始時の 10 個は **漢字だけの短い語**（1 文字、かな 0%）。
語彙は **すべて漢字 1 文字**に寄せている。動詞も `燃える` ではなく `燃` `斬` のように
1 個の漢字にして、接続詞で自然に文になるようにしている。
静かな / 確かな / 滑らかな は 1 漢字語 + 接続詞 `かな` で作る（静かな / 確かな / 滑かな）。
かなも 2 文字の語も辞書には入らないので、語彙は漢字だけ。
`焔を斬された硬刃` や `焔速く斬る硬刃`、`焔を貫る弾`、`潮の焔弾` のような名前。

語彙が満杯で 3 択を出すとき、**捨てる語は候補と重複しないものだけ**を選ぶ。

### 9. 「忘れる」で空きを作る

言葉鍛冶の **「忘れる」** を押すとモードが点ります。このときは語彙の語をクリックするだけで
**捨てられます**。武器や自身の文にある語は対象外です（それらは「忘れられない」）。

### 10. クリア報酬 — 言玉がそのまま入る

ステージを終えると**三択は無く、言玉が直接入る**。

| 結果 | 言玉 |
| --- | --- |
| クリア | `(100 + ステージ番号 × 100) × バフ倍率` |
| 負け | `(100 + 崩した敵の文 × 15) × バフ倍率` |

バフ倍率は `1 + (攻撃倍率 - 1) × 0.5 + (自分の文の力 - 1)`。つまり**自分の文を
鍛え込むほど言玉が増える**。基本で 200（1 面）〜 1000（9 面）、
倍率で最大 2 倍ほど。書庫では**言玉で恒久強化**を買えます。
ステージクリアしたら結果画面から**一度ホーム（タイトル画面）へ戻ります**。
次のステージはホームから選び直せます。

### 11. 辞書

使えるすべてのことばを一覧できます。カテゴリで絞り込んだり名前で検索したりできます。
開いている間は時間が止まります。

| | 開き方 |
| --- | --- |
| 戦闘中 | HUD の **「辞」** ボタン |
| 言葉鍛冶 | 鍛冶の **「辞書」** ボタン |

言葉鍛冶の上から開いても **鍛冶は閉じません**。閉じると元の画面（鍛冶）に戻るので、
語を組み立てた状態のまま意味を調べられます。
なお語を<strong>クリック</strong>しただけでも、鍛冶の下にその語の効果が出ます。

### 12. 敵も「文」でできている

敵の頭の上には **敵自身の文** が出ています。通常の敵は 2 語、ボスは 3 〜 5 語。
自分が作った武器の文で、その語を **斬り落とします**。

| 武器の文 | 斬る量 | 確率 |
| --- | --- | --- |
| 成立 | 1 語 | 15% |
| 熟語を含む | 2 語 | 45% |
| 述語（接続詞の合成）がある | 2 語 | 45% |
| 不成文 | 斬れない | — |

敵の文が **不成文** になると頭の上に「不成文」と出て、その敵は
**動かなくなり、ダメージの受けが 2.5 倍** になります。ボスは倒れません。
崩しても攻撃パターンが止まるだけです（0.3 倍の確率でしか斬り切れない）。

つまり **よく組んだ文ほど、敵の文を早く崩せる**。
威力で押し切るのとは別の、ことばの作り方で勝つ道があります。

### 14. 書庫 — 走った分が、次の走りに残る

クリア報酬と**敵の文を崩す**ときに **言玉**（書庫の通貨）が手に入ります
（崩すほうは行動が止まるぶん強いので多く付きます）。

| 入手 | 言玉 |
| --- | --- |
| ステージクリア | 100 + ステージ番号 × 100（バフ倍率で増える、10 節） |
| 敵の文を崩す | 2 / 体 + さらに 2 につき 1 |

累計はタイトル画面の **「文を崩した数」** に出ます。

書庫では **恒久強化** を買えます。

- **恒久強化** … 体力 / 攻撃 / 装甲 / 経験値 / 引き寄せ / 会 / **語彙**。
  段階を上げるほど値段が上がるので、使い切りはできない。
  保存は最終値で `stats.js` の `resolvePlayerStats` がそのまま読む。
- **語彙** … 毎回のランの最初から入る **語の数** を 1 つ増やす（最大 18 段階）。
  買った語を毎回入りにする仕組みは廃止。

**恒久の語を買って毎回その語を入れる仕組みは廃止**しました。
代わりに語彙の枠を広げるので、語そのものを増やさずに「持つ量」を増やせます。

どちらも次のランに持ち越す。死んでも失わない。

### 15. 経験値の引き寄せ

敵を倒すと経験値が落ち、近づくと引き寄せられます（拾いに行く必要はない）。
遠いところにあるものも **時間切れでは消えません**。
引き寄せは速度に上限があるので、通り過ぎたり振動したりしません。

## 操作

| | |
| --- | --- |
| <kbd>WASD</kbd> / <kbd>矢印</kbd> | 移動 |
| <kbd>スペース</kbd> | **押しっぱなしでダッシュ**（スタミナを消費） |
| <kbd>Q</kbd> | 言葉鍛冶の開閉 |
| <kbd>Esc</kbd> | 一時停止 / 閉じる |
| タッチ | 画面を長押ししてからドラッグで移動 |
| タッチ | 右下の **ダッシュ** を長押しでダッシュ |

ダッシュは移動速度の 3.1 倍。毎秒 34 のスタミナを消費し、
離れると毎秒 26 で回する。敵を弾き飛ばす。

**スマホ・タブレットでは右下に「ダッシュ」ボタンが出る。** タップも長押しも効く。
画面を長押しする操作は移動しか取れないので、移動する指とは別の指で押す。

武器は**自動で攻撃**します。狙いも自動で最も近い敵に合わせます。

## 中身

| | |
| --- | --- |
| 語 | 310 語（属性 82 / 武器語 30 / 効果 113 / 動詞 48 / 自身 19 / 接続 18）。**引けるのは実質語 213 語**（動詞 48 語はこれに重なる / 合計 261、武器語は 3 択で確率 22%、接続詞は語の後ろで切り替える）。語は**すべて漢字 1 文字**、接続詞（`された` `かな` `む` `ける` など 18 種）だけがひらがな |
| 接続詞 | 18 種。品詞（体言・する体言・い形容・な形容・用言）で結合を判定し、語ごとの絞り込み（`する` `つ` `かな` `む` `ける`）と例外（`く`＝響・沸・吐・穿・融・散・瞬・貫・焼・叩・浮・溶・跨・轟・裂・砕、`な` `に`＝な形容詞の `妙` と `急`、`かな`＝語幹が「〜か」になる `静` `確` `滑` `適` `華` `豪` `精` `良` `明` `優` `巧`、`む`＝「〜む」の `蝕` `踏` `挟` `掴` `嚇` `沈` `縮` `潜`、`ける`＝「〜ける」の `溶` `凍` `融` `焼` `焦` `砕` `潰` `冷`）も見る。1 回制限・名詞修飾も見る。順序は自由（接続詞どうしの隣接だけ不可）。**語をタップすると直後の接続詞が切り替わり、一周すると無し。語の右のマスで一覧からも選べる** |
| 文 | 1 文 = 10 文字まで。語は何個でも並べ替えられる。武器は最初 1 つ、武器語を得ると最大 3 つ |
| 熟語 | 45 種（3 字以上）。すべて「語彙から引ける語だけで」分割できるものだけ。**成立すると専用効果が乗り、さらに文の力が ×1.2 相当（+0.20）上がる** |
| 敵 | 通常 15 種 + ボス 4 体 |
| ステージ | 9 面 |

文の判定は `js/data/words.js` の **DP による最長一致分割** で行っています。
合成語（`焔刃` など）は分割辞書に載せず、別表 `PHRASE_BONUS` で扱っています。
載せると `焔` + `刃` の連結が分割不能になってしまうためです。
2 字の熟語（`火球` など）は廃止しました。文を自由に並べられるようになったので、
2 語の連結だけで効果が乗ると名前と効果がずれてしまうからです。

**語彙の原則: 1 文字の語は「単独で日本語の語になる」ものだけ。**
これまでは熟語の部品（`袈` `裟` `以` `攻` `一` `千` `角`…）を語として置いていたので、
語彙に引かれると `袈刺青硬剣` のような意味の無い名前になってしまいました。
部品は辞書に置かず、熟語は中身のある語だけで組み直しています。
`test/all.mjs` の「1 文字の語」で、許可リストに無い 1 文字語と
語だけで分割できない熟語を検出します。

**2 文字の語もかなを含む語も、辞書には置かない。**
`静かな刃` `確かな刃` `滑らかな刃` は 1 漢字語 + 接続詞 `かな` で作る
（静かな刃 / 確かな刃 / 滑かな刃）。語を 2 つに割って `静か` `確か` `滑らか` と置かない。
`華麗` `精密` `端正` のような 1 漢字語どうしの連結も置かない
（置くと `華` `麗` の連結が分割で `華麗` になり、品詞と効果が変わってしまう）。
`test/all.mjs` の「語彙」が許すのは接続詞だけ（ひらがな）です。

## 動かす

ビルドは何も要らない。静的ファイルを配信するだけでよい。

```bash
npm start            # http://localhost:8099
```

そのまま `index.html` を file:// で開いても動作しますが、
ES modules の制約でローカルサーバ経由の方を推奨します。

npm test             # 辞書 + シミュレーション + ブラウザ

npm run test:sim     # ヘッドレスで 1 ステージを最後まで回す
