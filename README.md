# ワードローグ / Wordrogue

> 言葉を組み合わせて武装する 2D ローグライク。
> **作った「文」が成立しなければ、その武器は無効になる。**

Vampire Survivors 系の放置アクションに、**日本語の文を組み立てる**仕組みを乗せたもの。
外部ライブラリなし・ビルド不要・画像ファイルなしの、依存ゼロのブラウザゲーム。

## 更新時のルール

- タイトル画面には必ず `Ver. X.YY` 形式のバージョンを表示する（表示箇所は `index.html` の `.title-version`）。
- ユーザー向けの更新を行うたびにバージョンを更新し、READMEなどの更新説明と合わせて画面上の表示も変更する。表示を削除したり、更新し忘れたりしないこと。現在の表示は `Ver. 1.48`。
- **`?v=` は、`index.html` と `js/` の全ファイルで 1 つにそろえる。** 版数は 1 か所（`index.html` の `.title-version`）を直し、残りは機械的に置き換える:

  ```bash
  sed -i 's|Ver\. 1\.30|Ver. 1.31|' index.html
  grep -rl '?v=' js/ index.html | while read f; do sed -i 's/?v=[0-9][0-9.]*/?v=1.35/g' "$f"; done
  ```

  モジュールの import にも `?v=` が付いている。ここを上げ忘れると、**更新したファイルがブラウザのキャッシュから読まれ、直したのに直らない**（`js/data/words.js?v=1.21` のまま単語を直した、など）。`npm test` が「共有カードと版表示」で照合するので、ずれていたらテストで止まる。
- **熟語は辞書から機械的に登録する。** `js/data/words.compounds.js` は自動生成で、手で編集しない。出典・ライセンス・再生成の手順は [docs/dictionary.md](docs/dictionary.md) を見ること。辞書に無い熟語を足すときは `js/data/words.phrase.js` に書く（生成分より優先される）。
- 公開後に反映を確かめるときは、タイトル下部の `Ver. X.YY` と、配信中のファイルの中身（`curl` で `?v=` を見る）の両方を見る。`Ctrl+Shift+R` までは利用者に求めなくてよい。
- 画面が白く固まる可能性を減らすため、起動とフレームの例外は `index.html` の `#fatal` が受け取って案内を出す。例外を握りつぶす場所を増やさず、案内を出せない環境（テスト）では `console.error` に落とす。
- 公開は GitHub Actions。`test` ジョブ（辞書・シミュレーション）が落ちると `deploy` ジョブが走らず、**古い版のまま公開が止まる**。push 前に `npm test` を通すこと。

## 武器のモーション

攻撃の**見た目**は `js/game/motions.js` が決める。当たり判定・威力・攻撃間隔は
`js/game/combat.js` のままで、モーションを足しても DPS は変わらない。

1 回の攻撃は 4 局面を持つ。

```
予備動作 (windup) → 打撃 (strike) → 振り抜け (follow) → 戻り (recover)
   構え・引き絞り      刃先が走る         勢いが残る       次の構えへ
```

### 武器種ごとに、動きそのものを変える

同じ「斬撃」でも、武器語によって振り方を変える。`WEAPON_MOTIONS[key].style` が描き方を決める。

| style | 武器 | 動き |
| --- | --- | --- |
| `wave` | 刃 | **斬撃を飛ばす。** 刃を離れた三日月が、手元から間合いの外周まで飛びながら扇いっぱいに広がる |
| `sweep` | 刀 | **左右に斬る。** 扇の端から端まで、右薙ぎと左薙ぎを交互に振り抜く |
| `forward` | 剣 | **前方に斬る。** 正面へ短く斬り込み、刃先が照準の方向へ走る |
| `smash` | 斧・槌 | 振りかぶって落とす。着弾で地面に輪と土煙 |
| `claw` / `bite` / `punch` | 爪・牙・拳 | 3 本の鉤爪 / 噛みつき / 連打 |
| `thrust` | 槍・矛 | 弧ではなく、前へ伸びる一線 |
| `ranged` / `cast` | 銃・弓・針 / 杖・玉 | 構えて放つ。筒先が光る |
| `whip` / `throw` | 鞭・鎖 / 還 | しなる線 / 回して投げる |

- **見た目の扇と間合いは、当たり判定と同じ値から作る。** `combat.js` の `attackShape()` が
  返す `reach`（届く距離）と `arc`（扇の角度）を、そのままモーションに渡す
  (`syncMotionShape()`)。軌跡が扇からはみ出すことも、届くのに描かれないこともない。
  扇は端から端まで振るので、**描いた範囲 = 当たる範囲**になる。
- **同じ武器でも振り方が交互に変わる。** 乱数は使わず、攻撃回数だけで決めるので、
  テストで同じ順序を再現できる。
- **予備動作は攻撃間隔に収める。** 連射武器でもモーションが積み上がらない。
- 攻撃の少し前（cd が予備動作の長さを切った時点）から構え始める。当たり判定は
  従来どおり cd が 0 になった瞬間なので、**攻撃間隔と威力は変わらない**。
  予備動作のあいだに文が変わっても、打撃の瞬間に扇と間合いを合わせ直す。
- 打撃の瞬間から、斬撃の軌跡（墨の縁・紙を抜く白・属性色の芯の 3 層）を描く。
  軌跡の外側には、当たる扇の外周を細い一線で示す。
- 検証は `node test/motion.test.js`。全武器にモーションがあり、局面が逆戻りせず、
  描画値が有限で、軌跡が扇と間合いの内側に収まり、性能が変わらないことを見る。
  描画そのものは `node test/render.test.js`（Canvas を差し替えて実際に `draw()` を通す）。

## 遊びかた

### 1. 文がそのまま武器の名前になる

武器は **10 文字までの文** です。文の並びは枠に嵌めず、**語を自由に並べます**。
並べた語と接続詞がそのまま **武器名** になります。武器レベルでは文の長さは変わりません。

| 並べた語 | 武器名 | 結果 |
| --- | --- | --- |
| 焔 + 必 + 剣 | `焔必剣` | **成立** — 斬撃 |
| 焔 + を + 斬 + られた + 硬 | `焔を斬られた硬` | **絶句** — 日本語として完成 |
| 焔 + の + 爆 + 裂 + する + 妙 + な + 刃 | `焔の爆裂する妙な刃` | **絶句** — 熟語「爆裂」に `する` |
| 静 + かに + 燃 + える + 聖 + なる + 炎 | `静かに燃える聖なる炎` | **絶句** — 連用修飾と連体の重なり |
| 発 + 電 + する + 剣 | `発電する剣` | **成立** — 二字熟語「発電」ボーナス + 述語 |
| 刃 + 弾 | `刃弾` | **不成文** — 武器語どうしは隣り合えない |
| 風 + の + 潮 + の + 銃 | `風の潮の銃` | **成立** — のが 2 回で少し減点 |

**成立の判定は 2 つ。** 連結した文字列が

1. 辞書で**完全に分割できる**（例: `焔の爆裂する妙な刃` → `焔` / `の` / `爆` / `裂` / `する` / `妙` / `な` / `刃`）
2. **実質語（接続詞でない語）を 2 つ以上**含む

**文の中の武器語が攻撃を決める。** 武器語は **基本武器の 16 語だけ**
（刃・剣・刀・斧・槌・槍・矛・牙・爪・弓・鞭・鎖・杖・拳・銃・針）。自動では付かず、
語として得るものです（次項）。文の後方から最初に見つかった武器語が攻撃を決めます。
武器語が文に無いときは、その武器の既定の型（剣なら斬撃、銃なら射撃…）になります。

武器語には **基本武器** と **特殊武器** があります。
基本武器（刃・剣・刀・斧・槌・槍・矛・牙・爪・弓・鞭・鎖・杖・拳・銃・針）は、それ単体でも武器として成立します。
特殊武器は**属性語と現象語だけ**（炎・水・岩・雷・光・闇・渦など）で、
**攻撃できる動詞が述語の形で付いている場合のみ** 武器として成立します（例：`天焦がす滅亡の光`）。
**環・弾・玉・球・壁・石・針・矢 … は武器語ではありません。**
形を表すただの語なので、語彙から引けるし、文のどこに置いてもよい（文末も含む）。
置いても攻撃の型は変わりません（型を決めるのは武器語だけ）。
武器の定義にある語（爆弾の「弾」、周回の「環」…）は **武器の名前**であって、
文の中で武器語として振る舞うわけではありません。

語のカテゴリは「文の中での働き」で決めます（1 語が複数に属してよい）。
属性（属性値を持ち文の属性を決める体言）／現象（属性値は無いが自然現象・力そのものを指す体言。渦。
属性と同じく特殊武器になれる）／形態（物の形・道具）／動詞（動作が主役）／
効果（修飾が主役）／接続（送り仮名）。
「プレイヤーに効く語だけの分類」は無い — どの語も武器の文で使う語で、
語の効果のうち <code>p.</code> を付けたキー（体力・移動・攻撃・経験値・幸運 …）だけが
部位強化でプレイヤーに乗る（武器の側では読まれない）。
動詞の形を持つ語は、本来の分類に加えて動詞も持ちます（震える・還る・走る）。
効果は意味でも変わります。受身で結ばれた語（〜された剣の語）は「受けた側」として、その語の効果が半減します。
撫でる・舐める・嗅ぐ・跨ぐのような、敵を倒すことに結びつかない動詞は辞書に入れていません
（潜る・跳ぶ・昇る・舞うなど、武器そのものの動きを表す動詞は残しています）。
動詞が無ければただの語で、攻撃の型は武器の既定のままになります。

| 語 | 効果 | 語 | 効果 |
| --- | --- | --- | --- |
| 刃 剣 刀 斧 戈 牙 爪 拳 | 斬撃 | 銃 玉 矢 針 弓 槍 矛 球 杖 | 射撃 |
| 珠 還 | 還り刃 | 雷（属性） | 連鎖 |
| 弾 石 | 爆弾 | 光（属性） | 光線 |
| 環 輪 | 軌道 | 鞭 鎖 | 薙ぎ |
| 壁 網 盾 | 城壁 | | |

この表は **武器そのものの既定の型**（`js/data/weapons.js` の定義と名前）です。
文の中にこれらの語を置いても型は変わらず、型を決めるのは基本武器の 16 語だけ。

**形を表す語どうしは隣り合えません**（`刃弾` は日本語に無いので不成立）。
語を 1 つ挟めば `焔刃弾` のように成立します。
`環`・`弾`・`刀` のように基本武器の語が 2 つ並ぶのも同じ理由で不成立です。

### 2. 武器語は戦闘中に得る

武器語（基本武器の 16 語）は語彙から引かれません。
**レベルアップの 3 択**に出ます（他の語より確率が低い — 22%・第 1 候補だけ）。
得た武器語は

- いまの武器の文に置けば、その**攻撃の型が変わる**
- そのまま**新しい武器の文**になる（武器は最大 3 つ）

語彙が**満杯でも**武器語は新しい文になります（古い語を 1 つ捨てる）。
3 つの枠が埋まっているときは 3 択で断られるので、鍛冶の **「文を外す」** で
1 本文を戻して空ける（外した語は語彙へ戻る。消えない）。
最初から持てる武器は **1 つだけ**。武器語を得るたびに 2 つ目、3 つ目が増えます。

**特殊武器は戦闘中にも作れる。** 語彙の語の右上に **＋** が出ることがあり、
それを押すとその語を頭にした**新しい文**ができます。

| 語 | ＋ の結果 |
| --- | --- |
| 属性語・現象語（光・雷・渦…） | **特殊武器**の文ができる。ただし攻撃できる動詞を述語に付けるまで**撃たない**（行は破線で「動詞待ち」） |
| 基本武器の語（剣・銃…） | その型の武器の文ができる（3 択と同じ） |
| 形態語（弾・環・玉…） | ＋ は出ない（武器の頭にはなれない） |

### 3. 語の種類

| 種別 | 例 | 効果 |
| --- | --- | --- |
| 属性 | 火 焔 猛 | 色と状態異常（炎上・減・感・毒） |
| 形態 | 剣 銃 弓 弾 矢 球 環 壁 | 物の形。**うち基本武器の 16 語だけが武器語**で、語彙から引けず 3 択で得る。残りはただの語（語彙から引けるが、型は決めない） |
| 効果 | 巨 貫 裂 散 | 数値を上げる |
| 動詞 | 燃 貫 凍 爆裂 | 1 個で 1 つの動作になる |
| 接続 | る の られた い | **直前の語に結合する**（次項）。3 択には出ない。語の横で切り替える |


**文の力**は「日本語としての自然さと完成度」で決まる。
`1 + 実質語のボーナス (1 語に 0.008) + 自然さ × 0.38 + 熟語ボーナス`。
自然さより実質語数（＝長さ）の重みは小さい — 長さだけで強くはならない。
属性で始まり、格・連体・連用修飾・述語があり、連体が名詞に重なる文ほど強い。
長いから強い、ではなく **自然だから強い**。

### 4. 接続詞は語の横。タップで切り替える

接続詞は **その語の直後**に付きます。別の置き場ではないので、
接続詞を足しても文の長さはその文字数分増えるだけです。

```
  焔  を  斬  られた  妙  な  刃
       接続詞は「その語の直後」
```

文の中の**語をタップすると、直後の接続詞が切り替わります**。
これは **部位強化の 1 文**にも同じように付いています（5. 参照）。
候補は **その語のプール（送り仮名の一覧）だけ**で、プールの順に回り、
一周すると**接続詞なし**になります。
**語の右にある接続詞のマスをタップすると一覧が出て、一発で選べます。**
まちがえたら **「戻す」** で 1 つ前に戻せます。

- `斬` → `る` → `られた` → `り` → **無し**
- `凍` → `る` → `える` → **無し**
- `滑` → `らかな` → `らかに` → `る` → **無し**
- `発` → `する` → `の` → `と` → `も` → `や` → `を` → `に` → `へ` → `で` → `から` → `まで` → `より` → `が` → `は` → **無し**

#### 語ごとの接続詞プール

接続詞は **品詞の規則 + 例外表ではなく、語ごとに持つ**（`js/data/words.pool.js`）。
語が持つ本物の送り仮名だけが付くので、`斬された` `凍ける` `滑かな` `舞く` のような
日本語に無い形は最初から作れない。

| 語 | プール | できる形 |
| --- | --- | --- |
| 名詞（表に無い語は全部） | の・と・も・や・を・に・へ・で・から・まで・より・が・は | `焔の` `焔と` `焔で` `焔が` |
| `斬` | る・られた・り | `斬る` `斬られた` `斬り` |
| `凍` | る・える | `凍る` `凍える` |
| `速` | い・く | `速い` `速く` |
| `妙` | な・に | `妙な` `妙に` |
| `静` | かな・かに | `静かな` `静かに` |
| `滑` | らかな・らかに・る | `滑らかな` `滑る` |
| `大` | きな・きい・きく | `大きな` `大きい` |
| `呪` | う・われた・いの・いを | `呪う` `呪いの` |

送り仮名は 1〜3 字（最長 `らかな` `やかな` `られた`）。辞書の最長 5 字・文の 10 字の上限に収まる。
かなの並びは必ず 1 つの送り仮名なので、分割（最少語数の DP）で割れ方は揺れない。

プールの各形は **役割** を持つ。文の判定は接続詞の文字列ではなく、選んだ形の役割で見る
（同じ `く` でも `速く` は連用、`貫く` は連体）。

| 役割 | 例 | 係り先 |
| --- | --- | --- |
| 連体 | `斬る` `速い` `妙な` `凍える` | 直後の名詞（か、連体の形の語） |
| 連用 | `速く` `妙に` `斬り` `必ず` | 節の後方の動詞か形容。名詞に係らない |
| 格「の」「と」「も」「や」 | `焔の` `焔と` `焔も` `焔や` | 直後の名詞（か、連体の形の語） |
| 格「を」 | `焔を` `呪いを` | 同じ節の後方の他動詞（連用修飾を挟める） |
| 格「に」「へ」「で」「から」「まで」「より」 | `焔に` `焔で` `焔から` | 同じ節の後方の動作か形容（連用修飾を挟める） |
| 主格「が」「は」 | `焔が` `焔は` | 同じ節の後方の述語。他動詞なら主体になれる語だけ |

**接続詞の直後だけを見るのではなく、節の終わりまで先読みして係り先を探します。**
連用形は目的語句を越えて後方の述語に係れます。
「深く敵を斬る剣」も「敵を深く斬る剣」も、深く → 斬る、敵を → 斬る の関係は同じです。

文が壊れる（**不成立**）のは次のときだけ。

1. **文末が接続詞で終わる。** NG「焔を斬る」「風の潮の」。
   接続詞は語に付くもので、文を閉じない。最後に語を置けば同じ並びが成立する
   （「焔を斬る剣」「風の潮の銃」）。
2. **接続詞が直前の語に結べない**（その語のプールに無い・直前が接続詞や先頭）。
   NG「斬された刃」「焔する剣」
3. **連体・「の」のあとに連用の語や裸の動詞が来る。** NG「斬る速く斬る剣」
4. **連用形の係り先が、節の終わりまでに見つからない。**
   NG「速く焔の刃」「妙に刃」「深く剣」「深く敵の剣」。
   連用形は名詞に係らない。名詞の前は連体の形（`〜い` `〜な` `〜る`）にすること。
   ただし目的語句や「の」句は越えられる: 「深く敵を斬る剣」「深く敵の剣を斬る剣」。
5. **「〜を」の受け先になる他動詞が、節の終わりまでに見つからない。**
   NG「焔を剣」「焔を強い剣」「敵を深く剣」。
   「〜を」と述語のあいだには 0 個以上の連用修飾語が入れる:
   「敵を深く斬る剣」「敵を静かに深く斬る剣」「敵を必ず深く斬る剣」。
   「〜に」「〜へ」も同じで、動作か形容で受ける: 「敵に深く刺す剣」。
6. **「〜を」の受け先が自動詞の形になる。** NG「焔を燃える剣」「焔を凍える刃」。
   燃える・凍える・舞う・輝く・翔ける のような自動詞は「〜を」を受け取れない。
   連用修飾を挟んでも同じ（「敵を深く燃える剣」✗）。
   「焔を燃やす剣」のように他動詞の形にすること。連用形で続く場合も同じ
   （「焔を舞い散る剣」✗ / 「焔を斬り裂く剣」✓）。
7. **「〜の」「〜が」「〜は」のあとに、前の語が主体になれない他動詞が来る。**
   NG「焔の斬る剣」「焔が斬る剣」。焔は斬る主体になれないので、
   「焔を斬る剣」と目的語で受ける。神・魔・魂のような主体になれる語だけ
   「神の斬る剣」「神が斬る剣」を許す。
   自動詞なら「焔の燃える剣」「焔が燃える剣」のように主体を表せる。

**部位の文は体の部位名が後ろに付く。** 「速い足」「静かな胴」「風の腕」のように、
連体形や「の」で終わる形は、その部位名に係る文として成立する（`implicitTail`）。
「速く足」「焔を足」のような連用・格で終わる形は成立しない。

**同じ接続詞を 2 回使うのは不成立ではなく、自然さの減点**（−0.4）。
「風の潮の銃」は成立する（少し弱くなる）。
ただし同じ「く」でも、動詞の連体（`貫く`）と形容の連用（`強く`）は
役割が違うので、重複として減点しない。

これらに当たらなくても、**武器語どうしが隣り合うと不成立**になる（`刃弾` など）。

| 例 | 文 | 結果 |
| --- | --- | --- |
| `焔を斬る剣` | 焔 を 斬 る 剣 | **絶句** |
| `敵を深く斬る剣` | 敵 を 深 く 斬 る 剣 | 成立。「を」と述語のあいだに連用修飾 |
| `深く敵を斬る剣` | 深 く 敵 を 斬 る 剣 | 成立。連用形が目的語句を越えて述語に係る |
| `敵を静かに深く斬る剣` | 敵 を 静 かに 深 く 斬 る 剣 | 成立。連用修飾が 2 つ |
| `深く敵の剣を斬る剣` | 深 く 敵 の 剣 を 斬 る 剣 | 成立。連用形が「の」句と目的語句を越える |
| `敵に深く刺す剣` | 敵 に 深 く 刺 す 剣 | 成立。「に」のあとにも連用修飾が入れる |
| `敵を深く斬り裂く剣` | 敵 を 深 く 斬 り 裂 く 剣 | 成立。連用形の複合動詞 |
| `焔を斬られた妙な剣` | 焔 を 斬 られた 妙 な 剣 | 成立。日本語として完成 |
| `凍える刃` | 凍 える 刃 | 成立 |
| `滑らかな刃` | 滑 らかな 刃 | 成立 |
| `呪いの毒を斬る刃` | 呪 いの 毒 を 斬 る 刃 | 成立 |
| `必ず斬る刃` | 必 ず 斬 る 刃 | 成立。連用のあとに動詞 |
| `焔に強い刃` | 焔 に 強 い 刃 | 成立。「に」は形容も受ける |
| `風の潮の銃` | 風 の 潮 の 銃 | 成立（の の重複で減点） |
| `斬された刃` | 斬 された 刃 | **不成立**（斬 のプールに された は無い） |
| `焔を剣` | 焔 を 剣 | **不成立**（を の受け先の動作が無い） |
| `敵を深く剣` | 敵 を 深 く 剣 | **不成立**（を の述語が無い） |
| `深く剣` | 深 く 剣 | **不成立**（連用形の係り先が無い） |
| `敵を燃える剣` | 敵 を 燃 える 剣 | **不成立**（自動詞は を を受けない） |
| `焔の斬る剣` | 焔 の 斬 る 剣 | **不成立**（焔は斬る主体になれない） |
| `焔を斬る` | 焔 を 斬 る | **不成立**（文末が接続詞。語を足せば成立） |

**自然さと完成度が、そのまま文の力になる**（`文の力 = 1 + 実質語のボーナス × 0.008 + 自然さ × 0.38 + 熟語ボーナス`）。
自然な文が、自然さで負ける不自然な文より弱くなることはない（重み付けは test/words.test.js で検査している）。
属性で始まり・格があり・連体があり・述語があって、文が閉じているほど強い。
羅列（接続詞を挟まずに 4 字以上つながる）や、形・動詞で始まる文は減点される。連接の減点は文字数に比例するので、長い名前ほど緩やかに弱くなる。

**連用修飾と目的語の加点は、語順に依りません。**
`敵を深く斬る剣` と `深く敵を斬る剣` はどちらも「連用修飾 +0.5」「目的語 +0.7」が乗り、
自然さは同じ 2.20（名文）になります。`敵を斬る剣` は 1.70 なので、連用修飾を足したほうが強い。
文頭の主題点（属性 +1.2 / 形 −0.8 / 効果 −0.3 / 動詞 −0.4）だけは、
どの語が文頭に来るかで変わります。これは「属性で始まる名前を好む」というゲームの設計です。

**分類が効果語でも、名詞として使われている語は「効果で始まる」と見なしません。**
`敵` は分類こそ効果語ですが、プールは名詞（`の・を・に・へ`）だけで、
`敵を斬る剣` のように目的語として使われます。文頭の語が格を取っているときは
名詞句の主題なので topicmod（−0.3）を付けません。`敵` だけの例外ではなく、
名詞だけのプールを持つ効果語 16 語（敵・精・端・霊・心・捷・衆・威・覇・骨・魂・気・己・皆・力・智）を
まとめて監査しています。

**「〜の」と「〜する」が同じ名詞に掛かる並びは減点する。**
`圧する毒の剣` は自然、`毒の圧する剣` は不自然。
前者は連体節が内側に入り、後者は格と連体節が同じ名詞に重なって係り損ねる。

| 項 | 加点 |
| --- | --- |
| 属性で始まる | +1.2 |
| 句切 `〜の` `〜へ` | +0.55 / 個 |
| 形容の連体 `〜い` `〜な` | +0.5 / 個 |
| 連用修飾 `〜く` `〜に` `〜り` | +0.5 / 個（最大 2 個ぶん。目的語句の前後どちらでも乗る） |
| 連体の重なり（連体節 + 形容が同じ名詞句に係る） | +0.45 |
| 動作（動詞） | +0.4 |
| 述語（`〜る` `〜られた`） | +0.6 |
| 目的語（`〜を`、後方の述語まで解決したもの） | +0.7 |
| 熟語（三字 / 二字） | +0.7 / +0.4 |
| 形で始まる | −0.8 |
| 効果で始まる（格を取らず裸で文頭に来たときだけ） | −0.3 |
| 動詞で始まる | −0.4 |
| 接続詞なしで 4 字以上連接 | −0.30 / 字（4 字目から） |
| 述語の後ろに修飾句がぶら下がる | −0.5 |
| 格句と連体節が同じ名詞に重なる | −0.5 |

自然さ **1.5 以上**で **名文**、**2.4 以上**で **絶句**。
`静かに燃える聖なる炎` は、連用修飾 `静かに`・述語 `燃える`・形容の連体
`聖なる`・連体の重なりをすべて満たすので **絶句** になります。
`静かに燃える炎` は連用修飾だけで **名文**、`燃える聖なる炎` は連体の重なりだけで
**名文**。連用形 (`斬り`) は後ろへ続く形なので述語の加点を二重に取りません。

### 5. プレイヤーの強化はメニューで（部位強化）

プレイヤー自身の強化は **戦闘中には行いません**。
タイトルの **部位強化** で、**頭・右手・左手・胸・胴・左足・右足** の
7 部位に語を入れると、その語の効果が能力に効きます。

### 語のランク

語はすべて **コモン** から始まります。**言葉くじ** で同じ語をもう一度引くと
1 段ずつ上がり、その語の効果 (武器の文でも部位でも) が伸びます。

| 段階 | 名前 | 効果 |
| --- | --- | --- |
| 0 | コモン | ×1.00 |
| 1 | アンコモン | ×1.12 |
| 2 | レア | ×1.25 |
| 3 | エピック | ×1.40 |
| 4 | レジェンド | ×1.60 |

最上位 (レジェンド) で重複したときだけ、言玉が 5 戻ります。
所持語の一覧では、ランクを **文字の札ではなく色だけ** で出します
(灰=コモン / 緑=アンコモン / 青=レア / 紫=エピック / 金=レジェンド。
ランク名と効果の倍率はマウスを乗せた案内で見られます)。
部位は**人型に置かず、普通に縦へ並べます** (1 部位 = 1 行)。
所持語は **部位欄の右側** に独立した一覧として置き、その中だけでスクロールします
(下に並べると、語が多いときにパネルの外へはみ出して下の語を掴めなくなるため)。
**体に効く語だけ** を並べ、武器の文で使う語 (剣・弾・炎 など) は隠します。

**1 部位 = 1 文**（**10 文字まで**、語の数に上限はない）。武器の文と**同じ仕組み・同じ操作**で、

- 所持語を部位の行へ**ドラッグ**すると、落とした位置に入る。
  語をタップして選んでから行を押しても入る（押した位置で並びが決まる）。
- 部位の中の語は**ドラッグで並べ替え**、**別の部位へ移動**、所持語の箱へドラッグで**取り外し**。
- 語をタップすると接続詞が順に回り、語の右の**接続詞**を押すと
  **戦闘中の言葉鍛冶と同じ一覧**（`.conn-picker`）が開く。
  付くのは **その語の送り仮名 (プール) と熟語の形だけ** (どの語にも付く自由な接続詞は選べません)。
  一覧は形だけを出し、選んだ結果が文になるかは部位の下の評価で示す。
  連体形・「の」で終わる形は部位名に係るので成立する（**速い足**・**風の腕**）
- **「戻す」**で直前の操作を 1 つ戻せる。各部位の**「空にする」**でまとめて外せる。
- 文が**成っているほど効きが伸びる**（`1 + (文の力 − 1) × 0.6` を ×0.6〜2.4 に収める）。
  不成文の部位は**何も効かない**ので、その旨が部位の下に出る

**語の意味そのものが部位の働きになる。** 速い足は移動、風の足も移動、
硬い胴は装甲、賢い頭は経験値と**語彙の枠**、速い腕は攻撃速度、炎の右手は武器の属性と炎上。
**恒久強化 (言玉で能力を買う仕組み) は廃止**したので、体力・攻撃・装甲・経験値・会心・吸引・語彙は
すべてこの意味の対応から取ります (14 節の表を参照)。
意味の対応は語の効果への**上乗せ**で、どの語も意味の分だけプラスに働く
（弱くなるだけの対応は作らない）。部位が不成文なら意味の対応も効かない。
移動はまとめて上限 90%、攻撃速度は 1.8 倍までに抑えて、語を並べても壊れない。

語の効果のうち、プレイヤーに効くキー（体力・移動・攻撃・経験値・幸運と、
装甲・回復・会心・盾・吸引）が体に乗り、武器にだけ効くキー（威力・弾速…）は
部位では読まれません。語の種類による分け方はしていません。
語データの**装甲は「点」**（硬 = 2、厚 = 4）で、部位では **1 点 = 3%** として
体の装甲（割合）に直します。部位に置いた語は戦闘中の語彙には入りません。

語は **言玉** を払う **言葉くじ** で手に入ります。プールは戦闘で使う語と同一で、
重複した語が出ると言玉が少し戻ります。
**言葉デッキ** も同じ画面で組み替えられ、戦闘開始時の語彙に入ります
（**最低 10 語**。満たない分は開始時に自動で補充。**接続詞はデッキに入りません**）。

### 6. 戦闘中はいつでも組み替えられる

<kbd>Q</kbd> で **言葉鍛冶** を開きます。開いている間だけ時間が止まるので、
戦況を見てから並び替えられます。

語彙の語を **文の行の好きな位置へドラッグ** すると、落とした x 座標に近い
語の境目へ差し込まれます。**ドラッグで語を置き換えることはしません。**
文の中の語もドラッグで並べ替えられます。どちらの語も消えません。
**文の語を語彙の箱へドラッグすると語彙へ戻ります。** 箱のどこへ落としても戻せます。
語と語のあいだには **✕ も隙間も「＋」も置かず**、そのまま連結して見えます。

**タップだけで組むこともできます。** ドラッグに向かない端末向け。

| 手順 | 結果 |
| --- | --- |
| 語彙の語を **タップ** | 語を持ち上げる（選択される） |
| 持ち上げた状態で **文の語か行の余白をタップ** | その位置 / 末尾に並べる |
| 持ち上げた状態で **語彙をタップ** | 文から語彙へ戻す |
| 文の語を **語彙の箱へドラッグ** | 文から語彙へ戻す（箱のどこでも） |
| 文の語を **タップ** | 直後の接続詞が順に切り替わる（一周で無し） |
| 文の語の **右の接続詞マス（無いときは右下の点）をタップ** | 使える接続詞の一覧から一発で選ぶ |
| **「戻す」ボタン** | 直前の操作を 1 つ取り消す（最大 40 回） |
| 文の語を **長押し** | 語を持ち上げて、以降はタップだけで配置できる |

持ち上げているときは対象が光ります。同じ語をもう一度タップすると元に戻ります。

**語彙が満杯でも外せます。** 戻すときは語彙で**最も古い 1 語が捨てられます**
（語を得るときの「古い語から捨てる」と同じ規則）。自分で選びたいときは
「忘れる」で空きを作ってから戻してください。

| ドロップ | 結果 |
| --- | --- |
| 語彙 → 文 | 文の行の落とした位置に差し込む。語彙の空きが 1 つ減る。**元の語は置き換えない** |
| 文 → 文 | 抜いて差し込む。語は消えない（行の末尾へ落としたら末尾に来る） |
| 文 → 語彙 | 語彙の箱のどこへ落としても戻す。**満杯なら最古の 1 語を捨てる** |
| 語彙 ⇄ 語彙 | 何もしない（語は消えない） |

ドラッグの判定は **7px**。それより動かなければ通常のタップとして扱います。
語彙の箱へ運べば語を外せます。文の行のどこへ落としても、落とした位置に
差し込み、語は置き換えません。
文の中の語は 7px 動くまでタップ（接続詞の切り替え）として扱われるので、
並べ替えたいときは **長押し** してから動かします。
接続詞を選び直すときは、語の右のマス（無いときは右下の点）をタップして一覧から選ぶのが早いです。

### 7. ことばは戦闘中のレベルアップの 3 択で獲得する

新しいことばはステージ終わりの報酬ではなく、**戦闘中のレベルアップ**と
**中ボスの宝箱**で入ります。
**接続詞は 3 択に出ない**（語の横で切り替えるだけだから）。
**武器語（基本武器）は出にくい**（確率 22%・第 1 候補だけ）。武器語を得ると武器が 1 つ増えます（最大 3 つ）。
形態語（弾・環・玉…）は武器語ではないので、3 択の「武器語」としては出ません（普通の語として出る）。

| レベル | 入ってくるもの |
| --- | --- |
| ふつう | 語彙に **3 択 1 個**（そのうち稀に武器語。得れば新しい武器。満杯なら古い語を 1 つ捨てる） |
| 5 の倍数 | 語彙に **3 択が 2 回**（順に選ぶ） |

3 択は **画面中央の大きな札** で出ます。**選択中はゲーム (敵・弾・ステージ時間) が止まり**、
背景を暗くして候補に集中できます。選択時間は 7 秒で、時間切れになると上の候補から 1 個入ります。
画面に出た 3 択を選ぶと次の 3 択が出ます（5 の倍数の 2 回分）。

### 8. 満杯のときは「捨てることば」を自分で選ぶ

語彙が満杯だと新しいことばが入りません。このときは先に **捨てることば** を 1 つ決めます。
語彙の一覧が全部出るので、消していい語を選んだあとで 3 択に進めます。

選ばずに時間切れになると **一番古い 1 語** が消えます。
**武器の文から語を外すのも、文ごと外すのも、満杯でもできる** — 語彙に戻るときは
一番古い 1 語を捨てて枠を作ります（語が消えて行き場をなくすことはありません）。

語彙の枠は **12 個**から始まります。中身は **言葉デッキ**(5. 参照)が入り、足りない分は短い語で補われます。枠は **部位強化** で広げます — 頭に「賢・智・心」のような**賢い語**を入れて文にすると 1 語あたり **+2 枠**(体じゅうで最大 +6 枠)。
**上限 30**、増やした分は **次のステージへ持ち越し**ます。引き直しボタンはありません。

語は創作的な固有名詞を避けた。**「太陽を焼く剣」「雷を貫く針」のように、そのままで意味が通る語**だけを使う。
効果語も「威力」「速攻」「防御」のように、その語が何を表すのかひと目でわかるものに限った。
属性語も「炭火」「夜」「金属」のような基本的な語に寄せた。造語（獄炎・妖刀・鋼鉄など）は置いていない。

デッキが足りないときに補われる語は **漢字だけの短い語**（1 文字、かな 0%）。
語彙は **すべて漢字 1 文字**に寄せている。動詞も `燃える` ではなく `燃` `斬` のように
1 個の漢字にして、送り仮名（接続詞）で自然に文になるようにしている。
静かな / 確かな / 滑らかな は 1 漢字語 + 送り仮名（`かな` `らかな`）で作る。
かなも 2 文字の語も辞書には入らないので、語彙は漢字だけ。
`焔を斬られた硬刃` や `速く斬る硬刃`、`焔を貫く弾`、`潮の焔弾` のような名前。

語彙が満杯で 3 択を出すとき、**捨てる語は候補と重複しないものだけ**を選ぶ。

### 9. 「忘れる」で空きを作る

言葉鍛冶の **「忘れる」** を押すとモードが点ります。このときは語彙の語をクリックするだけで
**捨てられます**。武器の文にある語は対象外です（それらは「忘れられない」）。

### 10. クリア報酬 — 言玉がそのまま入る

ステージを終えると**三択は無く、言玉が直接入る**。

| 結果 | 言玉 |
| --- | --- |
| クリア | `(100 + ステージ番号 × 100) × バフ倍率` |
| 負け | `(100 + 崩した敵の文 × 15) × バフ倍率` |

バフ倍率は `1 + (攻撃倍率 - 1) × 0.5 + (自分の文の力 - 1)`。つまり**自分の文を
鍛え込むほど言玉が増える**。基本で 200（1 面）〜 2000（19 面）、
倍率で最大 2 倍ほど。言玉は**言葉くじ**に使います(書庫タブ)。
ステージクリアしたら結果画面から**一度ホーム（タイトル画面）へ戻ります**。
次のステージはホームから選び直せます。

### 11. 辞書

使えるすべてのことばを一覧できます。カテゴリで絞り込んだり名前で検索したりできます。
開いている間は時間が止まります。

| | 開き方 |
| --- | --- |
| 戦闘中 | HUD の **「辞」** ボタン |
| 言葉鍛冶 | 鍛冶の **「辞書」** ボタン |

言葉鍛冶の上から開いても **鍛冶は閉じません**。閉じると元の画面（鍛冶）に戻るので、
語を組み立てた状態のまま意味を調べられます。
なお語を<strong>クリック</strong>しただけでも、鍛冶の下にその語の効果が出ます。

### 12. 敵も「文」でできている

敵の頭の上には **敵自身の文** が出ています。文字数は強さの段階で増えます。

- 雑魚（rank 1）… **1 文字**（コウモリ・スライム・子虫）
- そこそこ（rank 2）… **2 文字**（ゴブリン・スケルトン・ゴースト・アーチャーなど）
- 強敵（rank 3）… **3 文字**（レイス・墨鬼・ゴブリン主力）
- 精鋭（rank 4）… **4 文字**（韻獣・ゴーレム）
- 中ボス … **4 文字**（各章に 1 体）
- ボス … **5 文字**（全 6 体）

自分が作った武器の文で、その語を **斬り落とします**。

| 武器の文 | 斬る量 | 確率 |
| --- | --- | --- |
| 成立 | 1 語 | 15% |
| 熟語を含む | 2 語 | 45% |
| 述語（接続詞の合成）がある | 2 語 | 45% |
| 不成文 | 斬れない | — |

敵の文が **不成文** になると頭の上に「不成文」と出て、その敵は
**動かなくなり、ダメージの受けが 2.5 倍** になります。ボスは倒れません。
崩しても攻撃パターンが止まるだけです（ボスの文は斬れません）。

つまり **よく組んだ文ほど、敵の文を早く崩せる**。
威力で押し切るのとは別の、ことばの作り方で勝つ道があります。

**中ボス** は各章の半分ほどの時刻に出現します。章ボスとは別に、倒すと **宝箱** を落とします。
宝箱を拾うと **ランダムな言葉を 2 個** 入手できます（語彙が満杯なら最も古い語が入れ替わります）。
中ボスも文を斬って崩せます。

敵の行動は、追跡・不規則・突進・射撃・周回・潜行・群れに加えて、
**予備動作のあと一直線に踏み込む突進** と、**三方向に弾を撃つ射撃** があります。
中ボスは章ボスと同じ行動パターン（突進・弾幕・召喚・叩きつけなど）を組み合わせます。

### 13. 戦う場所は箱庭 — 開いたフィールドではなく、囲われた庭

ステージはぜんぶ **塀で囲まれた庭（箱庭）** です。外へは出られません。

| | |
| --- | --- |
| 壁 | 庭の外は闇。プレイヤーも敵も弾も**壁まで**。弾は壁で消え、爆弾はそこで炸裂する |
| 見え方 | カメラは庭の内側で止まる。庭が画面より小さければ**箱庭が丸ごと見えたまま**戦える |
| 湧き方 | 敵は**庭の内壁から**入ってくる。ボスと中ボスは**いちばん遠い縁**に現れる |
| 意匠 | 畝・花・木・竹・石・垣・砂・池・石畳・骨・灯籠を床に描く。**どれも当たり判定は無い**（持つのは壁だけ） |
| 庭の広さ | `arena: { w, h }`（中心が原点、`±w/2` が壁）。1 面 1600×1100 → 19 面 2400×1600 |

壁際で戦うと弾が壁で消えるので、**どこで撃つか**が場所で変わります。
庭から出ようとして迷うことはありません — ずっと庭の中にいるからです。

### 14. 書庫 — 走った分が、次の走りに残る

クリア報酬と**敵の文を崩す**ときに **言玉**（書庫の通貨）が手に入ります
（崩すほうは行動が止まるぶん強いので多く付きます）。

| 入手 | 言玉 |
| --- | --- |
| ステージクリア | 100 + ステージ番号 × 100（バフ倍率で増える、10 節） |
| 敵の文を崩す | 2 / 体 + さらに 2 につき 1 |

累計はタイトル画面の **「文を崩した数」** に出ます。

**言玉で能力を買う「恒久強化」は廃止**しました。言玉は言葉くじ(語を増やす・ランクを上げる)だけに使います。

プレイヤーを強くする道は **部位強化** だけです。恒久強化が与えていた効果は、
**部位に意味の合う語を入れる**と得られます(`stats.js` の `resolvePlayerStats`)。

| 恒久強化だった効果 | どこに何を入れるか | 例 |
| --- | --- | --- |
| 体力・回復 | 胸・胴・足に「命」の語 | 癒・花・草・魂 |
| 攻撃 | 腕・手・胸に「力」の語 | 強・力・剛・覇 |
| 装甲 | 胴・足に「守り」の語 | 硬・甲・鉄・盾 |
| 経験値・会心 | 頭に「賢さ」の語 | 賢・智・心・瞬 |
| 引き寄せ | 吸引の効果を持つ語 | 引・金・財・宝 |
| 語彙 | 頭に「賢さ」の語 | 賢・智・心(**+2 枠** / 最大 +6 枠) |

どれも **部位の文が成っていること**が条件で、不成文の部位は何も効きません。
部位に入れた語と、そこで広がった語彙の枠は **次のランに持ち越し**ます。死んでも失いません。

### 15. 経験値の引き寄せ

敵を倒すと経験値が落ち、近づくと引き寄せられます（拾いに行く必要はない）。
遠いところにあるものも **時間切れでは消えません**。
引き寄せは速度に上限があるので、通り過ぎたり振動したりしません。

### 16. 中二病の語と、意味のある演出

**語彙に、意味の通る中二病の一字語を足しました。** 造語ではなく、単独で日本語の
語になるものだけです。

| 種別 | 語 | 意味と効き |
| --- | --- | --- |
| 火 | 獄・劫・燼 | 獄炎・劫火・燼。燃やし、爆ぜ、長く燻る |
| 闇 | 冥・羅・刹・虚・幻 | 冥暗・羅刹・虚無・幻影。吸い、穿ち、追う |
| 雷・光 | 閃・煌 | 閃く一撃、煌めく光。会心と速さ |
| 風 | 迅・颯 | 迅雷・颯。速さと追い風 |
| 動詞 | 絶・終・戮・屠・討・刈・祓・祟・葬・刺・刻・駆・研・煉 | 絶つ・終わる・屠る・刈る・祓う…。意味どおりに斬る・刺す・燃やす |
| 効果 | 覇 | 覇気。威力と大きさと装甲 |

二字熟語は **獄炎・劫火・煉獄・羅刹・虚無・幻影・冥暗・絶滅・屠殺・祓魔・刺突・
覇気・終夜**、三字熟語は **獄炎剣・羅刹牙・冥暗刃・絶影刃・迅雷刃**。
効果は名前の意味から外れない範囲だけを選びました。**弱くなるだけの語は置いて
いません**（`遅` は重い一撃、`近` は近距離の会心、`少` は少数精鋭の威力、
`衰` は範囲と減速を伴う、のように必ず良い面を持たせています）。

**自然なのに作れなかった形も通しました。** `光り輝く剣`（光 + り + 輝く）、
`貫き通す剣`、`舞い散る剣`、`踏み潰す剣`、`突き刺す剣`、`穿ち貫く剣` のように、
語が本当に持つ送り仮名を足しています。逆に `焔を燃える剣`（自動詞 + を）や
`焔の斬る剣`（焔は斬る主体になれない）は不成立にしました。

**意味が能力と見た目に直結します。**

- **風** … 弾は渦と風切りの弧、斬撃は二重三重の風の刃、命中は風が抜ける輪。
  足に置けば移動が上がり、手に置けば武器が風を纏う（撃退と弾速）。
- **炎** … 火の粉と揺れる炎。燃焼の継続ダメージ。手に置けば武器が燃える。
- **氷** … 氷片と霜。命中で減速、凍結。足元の霧は冷たく光る。
- **雷** … 稲妻の枝分かれと感電。**光** … 光条と貫通。**闇** … 煙と影。
- **水** … 波紋。**草** … 舞う葉。**土・鉄** … 破片と土埃。**血** … 墨の飛沫。
  **金** … 金の粒と吸引。**毒** … 泡と毒の霧。
- **手の属性**は武器の属性・状態異常になり、**速い腕**は攻撃速度、**賢い頭**は
  経験値、**硬い胴**は装甲、**速い足**は移動になる。

**SE はすべて Web Audio の合成です。** 属性ごとに発射音と命中音を変え、
風はノイズの帯域を流して「ヒュッ」、雷は高く裂け、氷は澄んだ音、炎は低く唸ります。
UI にも開閉・選択・拒否・連斬の音を足し、全体はコンプレッサで潰して、
音が重なっても割れないようにしました。

**モーション。** カメラは少し遅れて追い、自機は歩くたびに弾み、撃つ瞬間に反り、
ダッシュでは伸びて残像と風切りを引きます。敵は被弾で跳ね、燃え・毒・氷・凍結・
痺れをそれぞれの形（炎の舌・泡・霜・氷膜・電気）でまとい、頭上の文も斬られて
短くなります。武器の精は属性の色に変わり、撃つたびに波紋を出します。連斬は
HUD に出て、レベルアップでは金の輪と画面の光が走ります。

## 中身

| | |
| --- | --- |
| 語 | 実質語 320 語（属性 100 / 現象 2 / 形態 35 / 効果 121 / 動詞 62）＋ 接続詞 119 種。**語彙から引けるのは 304 語**（形態 35 語のうち基本武器 16 語 = 武器語は語彙から引かず、3 択で確率 22%）。語は**すべて漢字 1 文字**、接続詞（送り仮名）だけがひらがな。語の効果は武器の文で読み、そのうち装甲・回復・吸血・会心・幸運・吸引・盾・体力のキーは部位強化でも体に乗る。**体に効く専用の語という分類は無い** |
| 接続詞 | **語ごとのプール**（`js/data/words.pool.js`）。名詞は共通の の・を・に・へ、動詞・形容は本物の送り仮名（`斬`＝る・られた・り・って、`凍`＝る・える・って・えて、`溶`＝ける・かす・かされた・けて・かして、`滑`＝らかな・らかに・る …）。結べるのはプールにある形だけ。判定は形の役割（連体・連用・格）で見る。同じ接続詞の重複は減点。**語をタップするとその語のプールだけが順に切り替わり、一周すると無し。語の右のマスで一覧からも選べる** |
| 文 | 1 文 = 10 文字まで。語は何個でも並べ替えられる。武器は最初 1 つ、武器語を得ると最大 3 つ |
| 攻撃の型 | 文が決める。述語の動詞が最優先 (`斬る`→斬撃 / `貫通する`→貫通 / `爆裂する`→爆発) で、無ければ武器語 (`刃`→斬撃 / `銃`→射撃)、属性語、武器の既定の順。**語 1 つの品詞では決めない** — `爆裂` `貫通` のような熟語は 1 語の名詞として扱い、中の動詞 (`爆` `貫`) では判定しない |
| 初期語 | 20 語（属性 9 / 効果 5 / 動詞 4 / 体に効く語 2）。`js/core/save.js` の `STARTER_WORDS` が唯一のソース。属性は**炎・氷・雷・毒・風・水・聖・鉄・闇**で、雷は「電」ではなく**雷そのもの**（電は `発電` `感電` の熟語の部品なのでくじで引く語に回した）。焔は炎と重なるので初期語には入れない。初期セットを変えたら `STARTER_REVISION` を上げ、古いセーブの入れ替え（`STARTER_SWAPS`）も追加すること |
| 部位 | 7 部位 (頭・右手・左手・胸・胴・左足・右足)。**1 部位 = 1 文**（10 文字まで、語の数は自由）。文が成ったぶんだけ効きが伸び、不成文なら何も効かない。操作 (ドラッグ・タップ・接続詞の一覧・戻す) は鍛冶の文とまったく同じ |
| 敵 | 通常 14 種 + 中ボス 19 体 + ボス 6 体。敵も文でできている（斬ると 1 語ずつ崩れる）。文字数は rank 1〜5（ボスは 5 文字） |
| 熟語 | 三字熟語 49 種 + 二字熟語 74 種。すべて「語彙から引ける語だけで」分割できるものだけ。**成立すると専用効果が乗り、さらに文の力が上がる**（三字 +0.20 / 二字 +0.10）。動作の二字熟語は送り仮名も持つ（`発電する` `凍結された`） |
| ステージ | **19 面。ぜんぶ箱庭型**（塀に囲まれた庭。広さと意匠は `arena` / `garden`） |

**見た目は紙と墨。** 地は和紙（`--bg: #f3eee1`）、パネルはその上の一枚、
文字は墨（`--fg: #232a38`）、差し色は朱（`--accent: #c1432b`）。
発光・ネオンはやめて、紙が沈む影と罫線で立体を出しています（`css/style.css` の `:root` を見れば色は全部そろう）。
canvas も同じ方針で、`lighter`（加算合成）は使っていません。敵・弾・紋は墨の輪郭つきで、
明るい地でも形が読める。敵の文は紙を白く抜いて墨で書きます。
ステージごとの地色は `js/data/stages.js` の `ground` / `color` / `accent`。
庭の外の闇と壁の色は、その `accent` からその場で混ぜています。

**ステージは箱庭（19 面すべて）。** 外へは出られない、塀で囲われた庭で戦います。

- **壁**: 庭の外は闇。プレイヤー・敵・弾はどれも壁までで、弾は壁で消え
  （爆弾はそこで炸裂し）、カメラも庭の内側で止まります。庭が画面より小さければ
  **箱庭が丸ごと見えたまま**戦います。
- **湧き方**: 敵は庭の**内壁から**入ってきます。ボスと中ボスは**いちばん遠い縁**に現れます。
- **意匠**: 畝・花・木・竹・石・垣・砂・池・石畳・骨・灯籠を床に描きます。
  どれも**当たり判定のない景色**で、当たり判定を持つのは壁だけです。
- 庭の広さは `arena: { w, h }`（中心が原点、`±w/2` が壁）、
  何を置くかは `garden`（`js/data/stages.js`）で決めます。
  1 面は 1600×1100、19 面は 2400×1600。

文の判定は `js/data/words.js` の **DP による最長一致分割** で行っています。
合成語（`焔刃` など）は分割辞書に載せず、別表 `PHRASE_BONUS` で扱っています。
載せると `焔` + `刃` の連結が分割不能になってしまうためです。
2 字の熟語は一度廃止し（`火球` など。2 語の連結だけで効果が乗り、名前と効果がずれた）、
いまは**実在する自然な二字熟語だけ**を選んで戻しています（`js/data/words.phrase.js` の `add2`）。

- 形を表す語（`刃` `弾` `球` `光` `雷`…）は二字熟語に使わない。効果は熟語の意味どおり（`発電`＝感電、`凍結`＝凍結、`反射`＝反射）で、三字熟語より小さい。
- 検出は文面中で**最長の 1 つだけ**。`大地震` は二字熟語 `大地` `地震` より三字熟語が勝つ。1 文に熟語を 2 つ作っても乗るのは 1 つ。
- **熟語の接続詞プール**: 動作の熟語は自分の送り仮名を持つ（`発電`＝`する`、`凍結`＝`する` `された`）。
  接続詞の直前の語が（接続詞を挟まずに）熟語になっているときだけ付く。`発電する剣` は成立、`電する` `発の電する` は不成立。
  熟語の形の役割（連体・述語）で文を判定する。言葉鍛冶では `発` `電` と並べて `電` をタップすると、`する` が先頭に出る。
- **熟語は 1 つの名詞**。中の語がもともと動詞でも、熟語の一部なら述語ではない
  （`爆風` の `爆` は攻撃動詞に数えない）。文末は必ず語で閉じるので、
  `発電する` だけで終わらせず `発電する剣` のように語を置く。

**語彙の原則: 1 文字の語は「単独で日本語の語になる」ものだけ。**
これまでは熟語の部品（`袈` `裟` `以` `攻` `一` `千` `角`…）を語として置いていたので、
語彙に引かれると `袈刺青硬剣` のような意味の無い名前になってしまいました。
部品は辞書に置かず、熟語は中身のある語だけで組み直しています。
`test/all.mjs` の「1 文字の語」で、許可リストに無い 1 文字語と
語だけで分割できない熟語を検出します。

**2 文字の語もかなを含む語も、辞書には置かない。**
`静かな刃` `確かな刃` `滑らかな刃` は 1 漢字語 + 送り仮名 `かな` / `らかな` で作る。
語を 2 つに割って `静か` `確か` `滑らか` と置かない。
`華麗` `精密` `端正` のような 1 漢字語どうしの連結も置かない
（置くと `華` `麗` の連結が分割で `華麗` になり、品詞と効果が変わってしまう）。
`test/all.mjs` の「語彙」が許すのは接続詞だけ（ひらがな）です。

## テスト

```bash
npm test             # 辞書 + 文法監査 + シミュレーション + ブラウザ
npm run test:words   # 辞書の健全性・文の成立判定
npm run test:grammar # 2 語 444,586 + 3 語 244,800 + 4 語以上 39,960 の文法監査
npm run test:sim     # ヘッドレスで 1 ステージを最後まで回す
npm run test:browser # Chrome を起動して実際に操作する (要 Chrome)
```

ブラウザテストは Chrome DevTools プロトコルでページを開き、
コンソールエラーがないこと・不成文で武器が無効化されること・
報酬とセーブまで通ることを確認します。

`test/meaning.test.js` は「語の意味がそのまま武器の性質になっているか」を、
実際に文を組んで `resolve()` した結果で確かめます。

- 動詞 62 語 … 述語にしたとき、意味どおりの攻撃の型（斬る→斬撃 / 貫く→貫通 /
  爆ぜる→爆発 / 響く→連鎖 / 舞う→周回）になるか。型を持たない動詞は効果で
  意味を表しているか
- 属性語 102 語 … 文の属性が語の属性になり、その属性の状態
  （炎上・凍結・感電・毒）が付くか
- 効果語・形態語 156 語 … 武器に効果が 1 つ以上乗るか
- 武器語 16 語 … 形と攻撃の型、素振り（末尾語 1 つ）で撃てるか
- 効果語の数字 … 意味どおりの能力値が上がるか

語を足したのに画面の数字が変わらない、というバグはここで止まります。

`npm test` はこれに加えて、文章の品質（文字化け `U+FFFD`・簡体字の混入）、
共有カードのメタ情報（`og:image` と実ファイルの存在）、
タイトルの `Ver.` と全 `?v=` の一致を機械的に見ます。
簡体字の一覧は `test/all.mjs` の `SIMPLIFIED` にあり、
日本語でも使う字（区・号・元・系・万・写…）は入れていません。

`test/grammar.test.mjs` は、辞書の全語 × 全接続詞形 × 全語の **2 語パターンを
444,586 通り**列挙し、次を機械的に確かめます。

- 自然な文の見本 89 件 (自然なのに落ちていないか)
- 不自然な文の見本 37 件 (不自然なのに成立していないか)
- 文末接続詞・「〜を」+自動詞・主体になれない「〜の」+他動詞が成立しないこと
- 全語と全接続詞形に、文を作れる相手が最低 1 つあること
- 自然さの指標が高い文ほど威力が高いこと
- 語の意味と部位の能力の対応、デバフだけの語が無いこと

さらに代表 40 語の全 3 語組 (244,800 通り) を標本検査します。

**連用修飾・目的語・述語の全順序テンプレート** (4 語以上) は、
役割クラスを全列挙して代表語と組み合わせます。

- `Adv* + O を + V + 名詞` / `O を + Adv* + V + 名詞`
- `Adv1 Adv2 + O を + V + 名詞` / `O を + Adv1 Adv2 + V + 名詞`
- `Adv1 Adv2 Adv3 + O を + V + 名詞` / `O を + Adv1 Adv2 Adv3 + V + 名詞`
- `Adv* + O の + 名詞 + を + V + 名詞` / `O の + 名詞 + を + Adv* + V + 名詞`
- `Adv* + O に + V + 名詞` / `O に + Adv* + V + 名詞`
- `Adv / VADV / O` の 6 順序 + 複合動詞 (`斬り裂く`)
- 連用形 + 名詞だけ、目的語 + 名詞だけ、自動詞 + を の不成立

役割クラスは ADV 64 形 (深く・静かに・必ず…)、OBJ 146 語 (敵を・剣を…)、
VERB 81 形 (斬る・貫く…)、VADV 63 形 (斬り・突き…)、INTR 46 形 (燃えて・震えて…)。
4 語以上は 39,960 通りを生成し、10 文字を超える 696 通りを除いた 39,264 通り
(成立 38,832 / 不成立 432) を検査します。2 語・3 語の否定形を含む全テンプレートの
検査は 41,181 通り (成立 38,832 / 不成立 2,349) です。全 3 役割の総当たり
(ADV 64 × OBJ 146 × VERB 81 × 両順序 = 1,513,728 通り、10 文字超 1,394 を除く
1,512,334 通り) は `checkConnectors` の一括監査でも 0 件の誤りを確認しています。

- API: `https://wordrogue-api.tatudragon0327.workers.dev`
  - `POST /api/submit` — `{ type: "word"|"bug", payload, turnstileToken }`
  - `GET /api/submissions` — 管理用 (ヘッダ `X-Admin-Token` 必須)
- ボット対策: Cloudflare Turnstile
- 管理画面: `admin.html` (admin token を入力して閲覧)
- Worker コード: `worker/` (wrangler.toml, src/index.js, schema.sql)
- admin token は `worker/.admin-token.txt` (gitignore 済み) に保存

## 支援 (Stripe)

プレイヤーからの寄付は Stripe Checkout で受け付ける。

- フロント: `donate.html`（タイトル画面の「支援する」から遷移）
- API:
  - `POST /api/donate/checkout` — `{ amount: 100..10000, name?, message? }` → `{ ok, id, url }`
  - `POST /api/stripe/webhook` — `checkout.session.completed` / `expired` を署名検証して D1 に記録
  - `GET /api/donations` — 管理用（`X-Admin-Token` 必須）
- 保存先: D1 `donations` テーブル（`session_id`, `amount`, `status=pending|paid`, ...）
- Worker secrets:
  - `STRIPE_SECRET_KEY` — Stripe の制限付き API キー (live)
  - `STRIPE_WEBHOOK_SECRET` — webhook endpoint の署名シークレット（`worker/.whsec.txt`、gitignore 済み）

  - webhook endpoint `we_1UVuFRFAqbq9azdkBzbMGg6Y` → `https://wordrogue-api.tatudragon0327.workers.dev/api/stripe/webhook`

## 公開

`.github/workflows/pages.yml` で `main` に push すると
GitHub Pages へ自動デプロイされます。ブラウザで
**設定 → Pages → Build and deployment → Source: GitHub Actions** を選択してください。

デプロイは `test` ジョブが通ったときだけ走ります。反映されたかは、
公開ページのタイトル下部の `Ver. X.YY` が最新かで確認できます。

### 共有カード

`index.html` の `og:image` / `twitter:card` は `assets/og.png` (1200×630) を指します。
SNS やチャットに URL を貼ったときに出るカードで、タイトル・タグライン・
文の例（`炎`+`の`+`爆裂`+`する`+`刃`）が入っています。
差し替えるときは同じ寸法で置き換えてください（`npm test` がファイルの存在を見ています）。
Apple のホーム画面用アイコンは `assets/logo-180.png` です。

### 初めてのプレイヤーへの案内

タイトルに「遊び方」（節ごとに開く読み物）と「チュートリアル」があり、
初回起動時はチュートリアルが自動で開きます。
タブの中に長い説明は置かず、**言葉鍛冶・強化・書庫・辞書を初めて開いたときだけ**
短い案内（`js/ui/tips.js`）を重ねます。一度出したタブは `save.d.tips` に記録され、
以後は各タブ右上の **「?」** からいつでも開き直せます。
くわしい規則はチュートリアルと遊び方にまとめています。
遊び方は 17 節を `<details>` で畳み、見出しだけを並べます (最初の 1 節だけ開く)。加えて、
**初めての 1 戦だけ** 3 / 17 / 31 秒に操作のヒントを 1 行ずつ出します
（移動 → ダッシュ → 言葉鍛冶）。一度最後まで出すと `save.d.guide` に記録され、
次のランからは出ません（`js/game/run.js` の `guideTick`）。
一時停止には操作の早見（`.pause-keys`）を置いています。

### 止まったとき

例外が出た場合や、`js/main.js` などの読み込みに失敗した場合は、
白い画面ではなく `#fatal` の案内（原因・再読み込み・詳細のコピー）が出ます。
セーブは `localStorage` にあるので、再読み込みすれば続きから遊べます。
