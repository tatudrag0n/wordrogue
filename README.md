# ワードローグ / Wordrogue

> 言葉を組み合わせて武装する 2D ローグライク。
> **作った「文」が成立しなければ、その武器は無効になる。**

Vampire Survivors 系の放置アクションに、**日本語の文を組み立てる**仕組みを乗せたもの。
外部ライブラリなし・ビルド不要・画像ファイルなしの、依存ゼロのブラウザゲーム。

---

## 遊びかた

### 1. 文がそのまま武器の名前になる

武器は **10 文字までの文** です。文の並びは枠に嵌めず、**語を自由に並べます**。
並べた語と接続詞がそのまま **武器名** になります。武器レベルでは文の長さは変わりません。

| 並べた語 | 武器名 | 結果 |
| --- | --- | --- |
| 焔 + 必 + 剣 | `焔必剣` | **成立** — 斬撃 |
| 焔 + を + 斬 + られた + 硬 | `焔を斬られた硬` | **絶句** — 日本語として完成 |
| 焔 + の + 爆 + 裂 + する + 妙 + な + 刃 | `焔の爆裂する妙な刃` | **絶句** — 熟語「爆裂」に `する` |
| 発 + 電 + する + 剣 | `発電する剣` | **成立** — 二字熟語「発電」ボーナス + 述語 |
| 刃 + 弾 | `刃弾` | **不成文** — 武器語どうしは隣り合えない |
| 風 + の + 潮 + の + 銃 | `風の潮の銃` | **成立** — のが 2 回で少し減点 |

**成立の判定は 2 つ。** 連結した文字列が

1. 辞書で**完全に分割できる**（例: `焔の爆裂する妙な刃` → `焔` / `の` / `爆` / `裂` / `する` / `妙` / `な` / `刃`）
2. **実質語（接続詞でない語）を 2 つ以上**含む

**文の中の武器語が攻撃を決める。** 武器語は **基本武器の 15 語だけ**
（刃・剣・刀・斧・槍・矛・牙・爪・弓・鞭・鎖・杖・拳・銃）。自動では付かず、
語として得るものです（次項）。文の後方から最初に見つかった武器語が攻撃を決めます。
武器語が文に無いときは、その武器の既定の型（剣なら斬撃、銃なら射撃…）になります。

武器語には **基本武器** と **特殊武器** があります。
基本武器（刃・剣・刀・斧・槍・矛・牙・爪・弓・鞭・鎖・杖・拳・銃）は、それ単体でも武器として成立します。
特殊武器は**属性語と現象語だけ**（炎・水・岩・雷・光・闇・渦など）で、
**攻撃できる動詞が述語の形で付いている場合のみ** 武器として成立します（例：`天焦がす滅亡の光`）。
**環・弾・玉・球・壁・塊・針・矢 … は武器語ではありません。**
形を表すただの語なので、語彙から引けるし、文のどこに置いてもよい（文末も含む）。
置いても攻撃の型は変わりません（型を決めるのは武器語だけ）。
武器の定義にある語（爆弾の「弾」、周回の「環」…）は **武器の名前**であって、
文の中で武器語として振る舞うわけではありません。

語のカテゴリは「文の中での働き」で決めます（1 語が複数に属してよい）。
属性（属性値を持ち文の属性を決める体言）／現象（属性値は無いが自然現象・力そのものを指す体言。渦。
属性と同じく特殊武器になれる）／形態（物の形・道具）／動詞（動作が主役）／
効果（修飾が主役）／接続（送り仮名）。
「プレイヤーに効く語だけの分類」は無い — どの語も武器の文で使う語で、
語の効果のうち <code>p.</code> を付けたキー（体力・移動・攻撃・経験値・幸運 …）だけが
部位強化でプレイヤーに乗る（武器の側では読まれない）。
動詞の形を持つ語は、本来の分類に加えて動詞も持ちます（震える・還る・走る）。
効果は意味でも変わります。受身で結ばれた語（〜された剣の語）は「受けた側」として、その語の効果が半減します。
撫でる・舐める・嗅ぐ・跨ぐのような、敵を倒すことに結びつかない動詞は辞書に入れていません
（潜る・跳ぶ・昇る・舞うなど、武器そのものの動きを表す動詞は残しています）。
動詞が無ければただの語で、攻撃の型は武器の既定のままになります。

| 語 | 効果 | 語 | 効果 |
| --- | --- | --- | --- |
| 刃 剣 刀 斧 戈 牙 爪 拳 | 斬撃 | 銃 玉 矢 針 弓 槍 矛 球 杖 | 射撃 |
| 珠 還 | 還り刃 | 雷（属性） | 連鎖 |
| 弾 塊 石 | 爆弾 | 光（属性） | 光線 |
| 環 輪 | 軌道 | 鞭 鎖 | 薙ぎ |
| 壁 網 盾 | 城壁 | | |

この表は **武器そのものの既定の型**（`js/data/weapons.js` の定義と名前）です。
文の中にこれらの語を置いても型は変わらず、型を決めるのは基本武器の 15 語だけ。

**形を表す語どうしは隣り合えません**（`刃弾` は日本語に無いので不成立）。
語を 1 つ挟めば `焔刃弾` のように成立します。
`環`・`弾`・`刀` のように基本武器の語が 2 つ並ぶのも同じ理由で不成立です。

### 2. 武器語は戦闘中に得る

武器語（基本武器の 15 語）は語彙から引かれません。
**レベルアップの 3 択**に出ます（他の語より確率が低い — 22%・第 1 候補だけ）。
得た武器語は

- いまの武器の文に置けば、その**攻撃の型が変わる**
- そのまま**新しい武器の文**になる（武器は最大 3 つ）

語彙が**満杯でも**武器語は新しい文になります（古い語を 1 つ捨てる）。
3 つの枠が埋まっているときは 3 択で断られるので、鍛冶の **「文を外す」** で
1 本文を戻して空ける（外した語は語彙へ戻る。消えない）。
最初から持てる武器は **1 つだけ**。武器語を得るたびに 2 つ目、3 つ目が増えます。

**特殊武器は戦闘中にも作れる。** 語彙の語の右上に **＋** が出ることがあり、
それを押すとその語を頭にした**新しい文**ができます。

| 語 | ＋ の結果 |
| --- | --- |
| 属性語・現象語（光・雷・渦…） | **特殊武器**の文ができる。ただし攻撃できる動詞を述語に付けるまで**撃たない**（行は破線で「動詞待ち」） |
| 基本武器の語（剣・銃…） | その型の武器の文ができる（3 択と同じ） |
| 形態語（弾・環・玉…） | ＋ は出ない（武器の頭にはなれない） |

### 3. 語の種類

| 種別 | 例 | 効果 |
| --- | --- | --- |
| 属性 | 火 焔 猛 | 色と状態異常（炎上・減・感・毒） |
| 形態 | 剣 銃 弓 弾 矢 球 環 壁 | 物の形。**うち基本武器の 15 語だけが武器語**で、語彙から引けず 3 択で得る。残りはただの語（語彙から引けるが、型は決めない） |
| 効果 | 巨 貫 裂 散 | 数値を上げる |
| 動詞 | 燃 貫 凍 爆裂 | 1 個で 1 つの動作になる |
| 接続 | る の られた い | **直前の語に結合する**（次項）。3 択には出ない。語の横で切り替える |


**文の力**は「日本語としての自然さと完成度」で決まる。
`1 + 実質語のボーナス (1 語に 0.008) + 自然さ × 0.38 + 熟語ボーナス`。
自然さより実質語数（＝長さ）の重みは小さい — 長さだけで強くはならない。
属性で始まり、格・連体・述語がある文ほど強い。
長いから強い、ではなく **自然だから強い**。

### 4. 接続詞は語の横。タップで切り替える

接続詞は **その語の直後**に付きます。別の置き場ではないので、
接続詞を足しても文の長さはその文字数分増えるだけです。

```
  焔  を  斬  られた  妙  な  刃
       接続詞は「その語の直後」
```

文の中の**語をタップすると、直後の接続詞が切り替わります**。
これは **部位強化の 1 文**にも同じように付いています（5. 参照）。
候補は **その語のプール（送り仮名の一覧）だけ**で、プールの順に回り、
一周すると**接続詞なし**になります。
**語の右にある接続詞のマスをタップすると一覧が出て、一発で選べます。**
まちがえたら **「戻す」** で 1 つ前に戻せます。

- `斬` → `る` → `られた` → `り` → **無し**
- `凍` → `る` → `える` → **無し**
- `滑` → `らかな` → `らかに` → `る` → **無し**
- `発` → `する` → `の` → `を` → `に` → `へ` → **無し**

#### 語ごとの接続詞プール

接続詞は **品詞の規則 + 例外表ではなく、語ごとに持つ**（`js/data/words.pool.js`）。
語が持つ本物の送り仮名だけが付くので、`斬された` `凍ける` `滑かな` `舞く` のような
日本語に無い形は最初から作れない。

| 語 | プール | できる形 |
| --- | --- | --- |
| 名詞（表に無い語は全部） | の・を・に・へ | `焔の` `焔を` |
| `斬` | る・られた・り | `斬る` `斬られた` `斬り` |
| `凍` | る・える | `凍る` `凍える` |
| `速` | い・く | `速い` `速く` |
| `妙` | な・に | `妙な` `妙に` |
| `静` | かな・かに | `静かな` `静かに` |
| `滑` | らかな・らかに・る | `滑らかな` `滑る` |
| `大` | きな・きい・きく | `大きな` `大きい` |
| `呪` | う・われた・いの・いを | `呪う` `呪いの` |

送り仮名は 1〜3 字（最長 `らかな` `やかな` `られた`）。辞書の最長 5 字・文の 10 字の上限に収まる。
かなの並びは必ず 1 つの送り仮名なので、分割（最少語数の DP）で割れ方は揺れない。

プールの各形は **役割** を持つ。文の判定は接続詞の文字列ではなく、選んだ形の役割で見る
（同じ `く` でも `速く` は連用、`貫く` は連体）。

| 役割 | 例 | あとに来てよいもの |
| --- | --- | --- |
| 連体 | `斬る` `速い` `妙な` `凍える` | 名詞（か、連体の形の語） |
| 連用 | `速く` `妙に` `斬り` `必ず` | 動詞か形容。名詞は不可 |
| 格「の」 | `焔の` `呪いの` | 名詞（か、連体の形の語） |
| 格「を」 | `焔を` `呪いを` | 動作（述語の形を持つ語） |
| 格「に」「へ」 | `焔に` `焔へ` | 動作か形容 |

文が壊れる（**不成立**）のは次のときだけ。

1. **文末が接続詞で終わる。** NG「焔を斬る」「風の潮の」。
   接続詞は語に付くもので、文を閉じない。最後に語を置けば同じ並びが成立する
   （「焔を斬る剣」「風の潮の銃」）。
2. **接続詞が直前の語に結べない**（その語のプールに無い・直前が接続詞や先頭）。
   NG「斬された刃」「焔する剣」
3. **連体・「の」のあとに連用の語や裸の動詞が来る。** NG「斬る速く斬る剣」
4. **連用のあとに名詞が来る。** NG「速く焔の刃」「妙に刃」
5. **「〜を」のあとに動作が無い。** NG「焔を剣」「焔を強い剣」
6. **「〜を」のあとに自動詞の形が来る。** NG「焔を燃える剣」「焔を凍える刃」。
   燃える・凍える・舞う・輝く・翔ける のような自動詞は「〜を」を受け取れない。
   「焔を燃やす剣」のように他動詞の形にすること。連用形で続く場合も同じ
   （「焔を舞い散る剣」✗ / 「焔を斬り裂く剣」✓）。
7. **「〜の」のあとに、前の語が主体になれない他動詞が来る。** NG「焔の斬る剣」。
   焔は斬る主体になれないので、「焔を斬る剣」と目的語で受ける。
   神・魔・魂のような主体になれる語だけ「神の斬る剣」を許す。
   自動詞なら「焔の燃える剣」「風の舞う剣」のように「の」で主体を表せる。

**部位の文は体の部位名が後ろに付く。** 「速い足」「静かな胴」「風の腕」のように、
連体形や「の」で終わる形は、その部位名に係る文として成立する（`implicitTail`）。
「速く足」「焔を足」のような連用・格で終わる形は成立しない。

**同じ接続詞を 2 回使うのは不成立ではなく、自然さの減点**（−0.4）。
「風の潮の銃」は成立する（少し弱くなる）。
ただし同じ「く」でも、動詞の連体（`貫く`）と形容の連用（`強く`）は
役割が違うので、重複として減点しない。

これらに当たらなくても、**武器語どうしが隣り合うと不成立**になる（`刃弾` など）。

| 例 | 文 | 結果 |
| --- | --- | --- |
| `焔を斬る剣` | 焔 を 斬 る 剣 | **絶句** |
| `焔を斬られた妙な剣` | 焔 を 斬 られた 妙 な 剣 | 成立。日本語として完成 |
| `凍える刃` | 凍 える 刃 | 成立 |
| `滑らかな刃` | 滑 らかな 刃 | 成立 |
| `呪いの毒を斬る刃` | 呪 いの 毒 を 斬 る 刃 | 成立 |
| `必ず斬る刃` | 必 ず 斬 る 刃 | 成立。連用のあとに動詞 |
| `焔に強い刃` | 焔 に 強 い 刃 | 成立。「に」は形容も受ける |
| `風の潮の銃` | 風 の 潮 の 銃 | 成立（の の重複で減点） |
| `斬された刃` | 斬 された 刃 | **不成立**（斬 のプールに された は無い） |
| `焔を剣` | 焔 を 剣 | **不成立**（を のあとに動作が無い） |
| `焔を斬る` | 焔 を 斬 る | **不成立**（文末が接続詞。語を足せば成立） |

**自然さと完成度が、そのまま文の力になる**（`文の力 = 1 + 実質語のボーナス × 0.008 + 自然さ × 0.38 + 熟語ボーナス`）。
自然な文が、自然さで負ける不自然な文より弱くなることはない（重み付けは test/words.test.js で検査している）。
属性で始まり・格があり・連体があり・述語があって、文が閉じているほど強い。
羅列（修飾のあいだに係り結びが無いまま語が 4 つ以上並ぶ）や、形・動詞で始まる文は減点される。

**「〜の」と「〜する」が同じ名詞に掛かる並びは減点する。**
`圧する毒の剣` は自然、`毒の圧する剣` は不自然。
前者は連体節が内側に入り、後者は格と連体節が同じ名詞に重なって係り損ねる。

| 項 | 加点 |
| --- | --- |
| 属性で始まる | +1.2 |
| 句切 `〜の` `〜へ` | +0.55 / 個 |
| 形容の連体 `〜い` `〜な` | +0.5 / 個 |
| 動作（動詞） | +0.4 |
| 述語（`〜る` `〜られた`） | +0.6 |
| 目的語（`〜を`） | +0.7 |
| 熟語（三字 / 二字） | +0.7 / +0.4 |
| 形で始まる | −0.8 |
| 効果で始まる | −0.3 |
| 動詞で始まる | −0.4 |
| 4 語が羅列 | −0.45 / 語（4 語目から） |
| 述語の後ろに修飾句がぶら下がる | −0.5 |
| 格句と連体節が同じ名詞に重なる | −0.5 |

### 5. プレイヤーの強化はメニューで（部位強化）

プレイヤー自身の強化は **戦闘中には行いません**。
タイトルの **部位強化** で、**頭・右腕・左腕・右手・左手・右足・左足・胸・胴** の
9 部位に語を入れると、その語の効果が能力に効きます。

**1 部位 = 1 文**（語は 2 つまで、接続詞込みで 8 文字）。武器の文と同じ仕組みで、

- 空いている枠を押すと選んだ語が入る。**入っている枠の語をもう一度押すと外れる**（✕ でも外れる）
- 語の右の「・」をタップすると接続詞が回り、**タップ long で一覧から選べる**。
  部位は**どの接続詞でも選べる**。一覧の **✓ は文が成る形**（効きが伸びる）、
  **✕ は不成文**（選べるが効果なし）。連用形や格で終わる形は ✕ になる。
  連体形・「の」で終わる形は部位名に係るので成立する（**速い足**・**風の腕**）
- 文が**成っているほど効きが伸びる**（`1 + (文の力 − 1) × 0.6` を ×0.6〜2.4 に収める）。
  不成文の部位は**何も効かない**ので、その旨が部位の下に出る

**語の意味そのものが部位の働きになる。** 速い足は移動、風の足も移動、
硬い胴は装甲、賢い頭は経験値、速い腕は攻撃速度、炎の右手は武器の属性と炎上。
意味の対応は語の効果への**上乗せ**で、どの語も意味の分だけプラスに働く
（弱くなるだけの対応は作らない）。部位が不成文なら意味の対応も効かない。
移動はまとめて上限 90%、攻撃速度は 1.8 倍までに抑えて、語を並べても壊れない。

語の効果のうち、プレイヤーに効くキー（体力・移動・攻撃・経験値・幸運と、
装甲・回復・会心・盾・吸引）が体に乗り、武器にだけ効くキー（威力・弾速…）は
部位では読まれません。語の種類による分け方はしていません。
語データの**装甲は「点」**（硬 = 2、厚 = 4）で、部位では **1 点 = 3%** として
体の装甲（割合）に直します。部位に置いた語は戦闘中の語彙には入りません。

語は **言玉** を払う **言葉くじ** で手に入ります。プールは戦闘で使う語と同一で、
重複した語が出ると言玉が少し戻ります。
**言葉デッキ** も同じ画面で組み替えられ、戦闘開始時の語彙に入ります
（**最低 10 語**。満たない分は開始時に自動で補充。**接続詞はデッキに入りません**）。

### 6. 戦闘中はいつでも組み替えられる

<kbd>Q</kbd> で **言葉鍛冶** を開きます。開いている間だけ時間が止まるので、
戦況を見てから並び替えられます。

語彙の語を **文の語へドラッグ** すると、その手前に差し込まれます。
**ドラッグで語を置き換えることはしません。** 落とした位置に入るだけで、元の語は残ります。
文の中の語もドラッグで並べ替えられます。どちらの語も消えません。
語と語のあいだには隙間を置かず、そのまま連結して見えます。

**タップだけで組むこともできます。** ドラッグに向かない端末向け。

| 手順 | 結果 |
| --- | --- |
| 語彙の語を **タップ** | 語を持ち上げる（選択される） |
| 持ち上げた状態で **文の語か末尾の＋をタップ** | その位置に並べる |
| 持ち上げた状態で **語彙をタップ** | 文から語彙へ戻す |
| 文の語の **✕ をタップ** | 文から語彙へ戻す（右上に重なっている） |
| 文の語を **タップ** | 直後の接続詞が順に切り替わる（一周で無し） |
| 文の語の **右の接続詞マス（無いときは右下の点）をタップ** | 使える接続詞の一覧から一発で選ぶ |
| **「戻す」ボタン** | 直前の操作を 1 つ取り消す（最大 40 回） |
| 文の語を **長押し** | 語を持ち上げて、以降はタップだけで配置できる |

持ち上げているときは対象が光ります。同じ語をもう一度タップすると元に戻ります。

**語彙が満杯でも外せます。** 戻すときは語彙で**最も古い 1 語が捨てられます**
（語を得るときの「古い語から捨てる」と同じ規則）。自分で選びたいときは
「忘れる」で空きを作ってから戻してください。

| ドロップ | 結果 |
| --- | --- |
| 語彙 → 文 | 落とした語の手前に差し込む。語彙の空きが 1 つ減る。**元の語は置き換えない** |
| 文 → 文 | 並びを変える。語は消えない（末尾の＋へ落としたら末尾に来る） |
| 文 → 語彙 | 語彙の空きへ戻す。**満杯なら最古の 1 語を捨てる**（落としたマスが埋まっていても戻す） |
| 語彙 ⇄ 語彙 | 何もしない（語は消えない） |

ドラッグの判定は **7px**。それより動かなければ通常のタップとして扱います。
語彙へ運べば語を外せます。文へ運ぶと手前に差し込み、語は置き換えません。
文の中の語は 7px 動くまでタップ（接続詞の切り替え）として扱われるので、
並べ替えたいときは **長押し** してから動かします。
接続詞を選び直すときは、語の右のマス（無いときは右下の点）をタップして一覧から選ぶのが早いです。

### 7. ことばは戦闘中のレベルアップの 3 択で獲得する

新しいことばはステージ終わりの報酬ではなく、**戦闘中のレベルアップ**で入ります。
**接続詞は 3 択に出ない**（語の横で切り替えるだけだから）。
**武器語（基本武器）は出にくい**（確率 22%・第 1 候補だけ）。武器語を得ると武器が 1 つ増えます（最大 3 つ）。
形態語（弾・環・玉…）は武器語ではないので、3 択の「武器語」としては出ません（普通の語として出る）。

| レベル | 入ってくるもの |
| --- | --- |
| ふつう | 語彙に **3 択 1 個**（そのうち稀に武器語。得れば新しい武器。満杯なら古い語を 1 つ捨てる） |
| 5 の倍数 | 語彙に **3 択が 2 回**（順に選ぶ） |

3 択は **7 秒**。時間切れになると上の候補から 1 個入ります。**時間は止まりません。**
画面に出た 3 択を選ぶと次の 3 択が出ます（5 の倍数の 2 回分）。

### 8. 満杯のときは「捨てることば」を自分で選ぶ

語彙が満杯だと新しいことばが入りません。このときは先に **捨てることば** を 1 つ決めます。
語彙の一覧が全部出るので、消していい語を選んだあとで 3 択に進めます。

選ばずに時間切れになると **一番古い 1 語** が消えます。
**武器の文から語を外すのも、文ごと外すのも、満杯でもできる** — 語彙に戻るときは
一番古い 1 語を捨てて枠を作ります（語が消えて行き場をなくすことはありません）。

語彙の枠は **12 個**から始まります。中身は **言葉デッキ**（5. 参照）が入り、足りない分は短い語で補われます。**書庫の言玉**で 1 個ずつ広げられます（恒久強化「語彙」）。
**上限 30**、増やした分は **次のステージへ持ち越し**ます。引き直しボタンはありません。

語は創作的な固有名詞を避けた。**「太陽を焼く剣」「雷を貫く針」のように、そのままで意味が通る語**だけを使う。
効果語も「威力」「速攻」「防御」のように、その語が何を表すのかひと目でわかるものに限った。
属性語も「炭火」「夜」「金属」のような基本的な語に寄せた。造語（獄炎・妖刀・鋼鉄など）は置いていない。

デッキが足りないときに補われる語は **漢字だけの短い語**（1 文字、かな 0%）。
語彙は **すべて漢字 1 文字**に寄せている。動詞も `燃える` ではなく `燃` `斬` のように
1 個の漢字にして、送り仮名（接続詞）で自然に文になるようにしている。
静かな / 確かな / 滑らかな は 1 漢字語 + 送り仮名（`かな` `らかな`）で作る。
かなも 2 文字の語も辞書には入らないので、語彙は漢字だけ。
`焔を斬られた硬刃` や `速く斬る硬刃`、`焔を貫く弾`、`潮の焔弾` のような名前。

語彙が満杯で 3 択を出すとき、**捨てる語は候補と重複しないものだけ**を選ぶ。

### 9. 「忘れる」で空きを作る

言葉鍛冶の **「忘れる」** を押すとモードが点ります。このときは語彙の語をクリックするだけで
**捨てられます**。武器の文にある語は対象外です（それらは「忘れられない」）。

### 10. クリア報酬 — 言玉がそのまま入る

ステージを終えると**三択は無く、言玉が直接入る**。

| 結果 | 言玉 |
| --- | --- |
| クリア | `(100 + ステージ番号 × 100) × バフ倍率` |
| 負け | `(100 + 崩した敵の文 × 15) × バフ倍率` |

バフ倍率は `1 + (攻撃倍率 - 1) × 0.5 + (自分の文の力 - 1)`。つまり**自分の文を
鍛え込むほど言玉が増える**。基本で 200（1 面）〜 1000（9 面）、
倍率で最大 2 倍ほど。書庫では**言玉で恒久強化**を買えます。
ステージクリアしたら結果画面から**一度ホーム（タイトル画面）へ戻ります**。
次のステージはホームから選び直せます。

### 11. 辞書

使えるすべてのことばを一覧できます。カテゴリで絞り込んだり名前で検索したりできます。
開いている間は時間が止まります。

| | 開き方 |
| --- | --- |
| 戦闘中 | HUD の **「辞」** ボタン |
| 言葉鍛冶 | 鍛冶の **「辞書」** ボタン |

言葉鍛冶の上から開いても **鍛冶は閉じません**。閉じると元の画面（鍛冶）に戻るので、
語を組み立てた状態のまま意味を調べられます。
なお語を<strong>クリック</strong>しただけでも、鍛冶の下にその語の効果が出ます。

### 12. 敵も「文」でできている

敵の頭の上には **敵自身の文** が出ています。通常の敵は 2 語、ボスは 3 〜 5 語。
自分が作った武器の文で、その語を **斬り落とします**。

| 武器の文 | 斬る量 | 確率 |
| --- | --- | --- |
| 成立 | 1 語 | 15% |
| 熟語を含む | 2 語 | 45% |
| 述語（接続詞の合成）がある | 2 語 | 45% |
| 不成文 | 斬れない | — |

敵の文が **不成文** になると頭の上に「不成文」と出て、その敵は
**動かなくなり、ダメージの受けが 2.5 倍** になります。ボスは倒れません。
崩しても攻撃パターンが止まるだけです（ボスの文は斬れません）。

つまり **よく組んだ文ほど、敵の文を早く崩せる**。
威力で押し切るのとは別の、ことばの作り方で勝つ道があります。

### 14. 書庫 — 走った分が、次の走りに残る

クリア報酬と**敵の文を崩す**ときに **言玉**（書庫の通貨）が手に入ります
（崩すほうは行動が止まるぶん強いので多く付きます）。

| 入手 | 言玉 |
| --- | --- |
| ステージクリア | 100 + ステージ番号 × 100（バフ倍率で増える、10 節） |
| 敵の文を崩す | 2 / 体 + さらに 2 につき 1 |

累計はタイトル画面の **「文を崩した数」** に出ます。

書庫では **恒久強化** を買えます。

- **恒久強化** … 体力 / 攻撃 / 装甲（1 段階 8%、最大 8 段階で 64%）/ 経験値 / 引き寄せ / 会 / **語彙**。
  段階を上げるほど値段が上がるので、使い切りはできない。
  保存は最終値で `stats.js` の `resolvePlayerStats` がそのまま読む。
- **語彙** … 毎回のランの最初から入る **語の数** を 1 つ増やす（最大 18 段階）。
  買った語を毎回入りにする仕組みは廃止。

**恒久の語を買って毎回その語を入れる仕組みは廃止**しました。
代わりに語彙の枠を広げるので、語そのものを増やさずに「持つ量」を増やせます。

どちらも次のランに持ち越す。死んでも失わない。

### 15. 経験値の引き寄せ

敵を倒すと経験値が落ち、近づくと引き寄せられます（拾いに行く必要はない）。
遠いところにあるものも **時間切れでは消えません**。
引き寄せは速度に上限があるので、通り過ぎたり振動したりしません。

### 16. 中二病の語と、意味のある演出

**語彙に、意味の通る中二病の一字語を足しました。** 造語ではなく、単独で日本語の
語になるものだけです。

| 種別 | 語 | 意味と効き |
| --- | --- | --- |
| 火 | 獄・劫・燼 | 獄炎・劫火・燼。燃やし、爆ぜ、長く燻る |
| 闇 | 冥・羅・刹・虚・幻 | 冥暗・羅刹・虚無・幻影。吸い、穿ち、追う |
| 雷・光 | 閃・煌 | 閃く一撃、煌めく光。会心と速さ |
| 風 | 迅・颯 | 迅雷・颯。速さと追い風 |
| 動詞 | 絶・終・戮・屠・討・刈・祓・祟・葬・刺・刻・駆・研・煉 | 絶つ・終わる・屠る・刈る・祓う…。意味どおりに斬る・刺す・燃やす |
| 効果 | 覇 | 覇気。威力と大きさと装甲 |

二字熟語は **獄炎・劫火・煉獄・羅刹・虚無・幻影・冥暗・絶滅・屠殺・祓魔・刺突・
覇気・終夜**、三字熟語は **獄炎剣・羅刹牙・冥暗刃・絶影刃・迅雷刃**。
効果は名前の意味から外れない範囲だけを選びました。**弱くなるだけの語は置いて
いません**（`遅` は重い一撃、`近` は近距離の会心、`少` は少数精鋭の威力、
`衰` は範囲と減速を伴う、のように必ず良い面を持たせています）。

**自然なのに作れなかった形も通しました。** `光り輝く剣`（光 + り + 輝く）、
`貫き通す剣`、`舞い散る剣`、`踏み潰す剣`、`突き刺す剣`、`穿ち貫く剣` のように、
語が本当に持つ送り仮名を足しています。逆に `焔を燃える剣`（自動詞 + を）や
`焔の斬る剣`（焔は斬る主体になれない）は不成立にしました。

**意味が能力と見た目に直結します。**

- **風** … 弾は渦と風切りの弧、斬撃は二重三重の風の刃、命中は風が抜ける輪。
  足に置けば移動が上がり、手に置けば武器が風を纏う（撃退と弾速）。
- **炎** … 火の粉と揺れる炎。燃焼の継続ダメージ。手に置けば武器が燃える。
- **氷** … 氷片と霜。命中で減速、凍結。足元の霧は冷たく光る。
- **雷** … 稲妻の枝分かれと感電。**光** … 光条と貫通。**闇** … 煙と影。
- **水** … 波紋。**草** … 舞う葉。**土・鉄** … 破片と土埃。**血** … 墨の飛沫。
  **金** … 金の粒と吸引。**毒** … 泡と毒の霧。
- **手の属性**は武器の属性・状態異常になり、**速い腕**は攻撃速度、**賢い頭**は
  経験値、**硬い胴**は装甲、**速い足**は移動になる。

**SE はすべて Web Audio の合成です。** 属性ごとに発射音と命中音を変え、
風はノイズの帯域を流して「ヒュッ」、雷は高く裂け、氷は澄んだ音、炎は低く唸ります。
UI にも開閉・選択・拒否・連斬の音を足し、全体はコンプレッサで潰して、
音が重なっても割れないようにしました。

**モーション。** カメラは少し遅れて追い、自機は歩くたびに弾み、撃つ瞬間に反り、
ダッシュでは伸びて残像と風切りを引きます。敵は被弾で跳ね、燃え・毒・氷・凍結・
痺れをそれぞれの形（炎の舌・泡・霜・氷膜・電気）でまとい、頭上の文も斬られて
短くなります。武器の精は属性の色に変わり、撃つたびに波紋を出します。連斬は
HUD に出て、レベルアップでは金の輪と画面の光が走ります。

## 中身

| | |
| --- | --- |
| 語 | 実質語 321 語（属性 100 / 現象 2 / 形態 36 / 効果 121 / 動詞 62）＋ 接続詞 119 種。**語彙から引けるのは 306 語**（形態 36 語のうち基本武器 15 語 = 武器語は語彙から引かず、3 択で確率 22%）。語は**すべて漢字 1 文字**、接続詞（送り仮名）だけがひらがな。語の効果は武器の文で読み、そのうち装甲・回復・吸血・会心・幸運・吸引・盾・体力のキーは部位強化でも体に乗る。**体に効く専用の語という分類は無い** |
| 接続詞 | **語ごとのプール**（`js/data/words.pool.js`）。名詞は共通の の・を・に・へ、動詞・形容は本物の送り仮名（`斬`＝る・られた・り・って、`凍`＝る・える・って・えて、`溶`＝ける・かす・かされた・けて・かして、`滑`＝らかな・らかに・る …）。結べるのはプールにある形だけ。判定は形の役割（連体・連用・格）で見る。同じ接続詞の重複は減点。**語をタップするとその語のプールだけが順に切り替わり、一周すると無し。語の右のマスで一覧からも選べる** |
| 文 | 1 文 = 10 文字まで。語は何個でも並べ替えられる。武器は最初 1 つ、武器語を得ると最大 3 つ |
| 部位 | 9 部位。**1 部位 = 1 文**（2 語まで、接続詞込みで 8 文字）。文が成ったぶんだけ効きが伸び、不成文なら何も効かない。接続詞の操作は鍛冶の文と同じ |
| 敵 | 通常 15 種 + ボス 4 体。敵も文でできている（斬ると 1 語ずつ崩れる） |
| 熟語 | 三字熟語 49 種 + 二字熟語 74 種。すべて「語彙から引ける語だけで」分割できるものだけ。**成立すると専用効果が乗り、さらに文の力が上がる**（三字 +0.20 / 二字 +0.10）。動作の二字熟語は送り仮名も持つ（`発電する` `凍結された`） |
| ステージ | 9 面 |

**見た目は紙と墨。** 地は和紙（`--bg: #f3eee1`）、パネルはその上の一枚、
文字は墨（`--fg: #232a38`）、差し色は朱（`--accent: #c1432b`）。
発光・ネオンはやめて、紙が沈む影と罫線で立体を出しています（`css/style.css` の `:root` を見れば色は全部そろう）。
canvas も同じ方針で、`lighter`（加算合成）は使っていません。敵・弾・紋は墨の輪郭つきで、
明るい地でも形が読める。敵の文は紙を白く抜いて墨で書きます。
ステージごとの地色は `js/data/stages.js` の `ground` / `color` / `accent`。

文の判定は `js/data/words.js` の **DP による最長一致分割** で行っています。
合成語（`焔刃` など）は分割辞書に載せず、別表 `PHRASE_BONUS` で扱っています。
載せると `焔` + `刃` の連結が分割不能になってしまうためです。
2 字の熟語は一度廃止し（`火球` など。2 語の連結だけで効果が乗り、名前と効果がずれた）、
いまは**実在する自然な二字熟語だけ**を選んで戻しています（`js/data/words.phrase.js` の `add2`）。

- 形を表す語（`刃` `弾` `球` `光` `雷`…）は二字熟語に使わない。効果は熟語の意味どおり（`発電`＝感電、`凍結`＝凍結、`反射`＝反射）で、三字熟語より小さい。
- 検出は文面中で**最長の 1 つだけ**。`大地震` は二字熟語 `大地` `地震` より三字熟語が勝つ。1 文に熟語を 2 つ作っても乗るのは 1 つ。
- **熟語の接続詞プール**: 動作の熟語は自分の送り仮名を持つ（`発電`＝`する`、`凍結`＝`する` `された`）。
  接続詞の直前の語が（接続詞を挟まずに）熟語になっているときだけ付く。`発電する剣` は成立、`電する` `発の電する` は不成立。
  熟語の形の役割（連体・述語）で文を判定する。言葉鍛冶では `発` `電` と並べて `電` をタップすると、`する` が先頭に出る。
- **熟語は 1 つの名詞**。中の語がもともと動詞でも、熟語の一部なら述語ではない
  （`爆風` の `爆` は攻撃動詞に数えない）。文末は必ず語で閉じるので、
  `発電する` だけで終わらせず `発電する剣` のように語を置く。

**語彙の原則: 1 文字の語は「単独で日本語の語になる」ものだけ。**
これまでは熟語の部品（`袈` `裟` `以` `攻` `一` `千` `角`…）を語として置いていたので、
語彙に引かれると `袈刺青硬剣` のような意味の無い名前になってしまいました。
部品は辞書に置かず、熟語は中身のある語だけで組み直しています。
`test/all.mjs` の「1 文字の語」で、許可リストに無い 1 文字語と
語だけで分割できない熟語を検出します。

**2 文字の語もかなを含む語も、辞書には置かない。**
`静かな刃` `確かな刃` `滑らかな刃` は 1 漢字語 + 送り仮名 `かな` / `らかな` で作る。
語を 2 つに割って `静か` `確か` `滑らか` と置かない。
`華麗` `精密` `端正` のような 1 漢字語どうしの連結も置かない
（置くと `華` `麗` の連結が分割で `華麗` になり、品詞と効果が変わってしまう）。
`test/all.mjs` の「語彙」が許すのは接続詞だけ（ひらがな）です。

## 動かす

ビルドは何も要らない。静的ファイルを配信するだけでよい。

```bash
npm start            # http://localhost:8099
```

そのまま `index.html` を file:// で開いても動作しますが、
ES modules の制約でローカルサーバ経由の方を推奨します。

## テスト

```bash
npm test             # 辞書 + 文法監査 + シミュレーション + ブラウザ
npm run test:words   # 辞書の健全性・文の成立判定
npm run test:grammar # 全 2 語パターン (447,581 通り) の文法監査
npm run test:sim     # ヘッドレスで 1 ステージを最後まで回す
npm run test:browser # Chrome を起動して実際に操作する (要 Chrome)
```

ブラウザテストは Chrome DevTools プロトコルでページを開き、
コンソールエラーがないこと・不成文で武器が無効化されること・
報酬とセーブまで通ることを確認します。

`test/grammar.test.mjs` は、辞書の全語 × 全接続詞形 × 全語の **2 語パターンを
447,581 通り**列挙し、次を機械的に確かめます。

- 自然な文の見本 (自然なのに落ちていないか)
- 不自然な文の見本 (不自然なのに成立していないか)
- 文末接続詞・「〜を」+自動詞・主体になれない「〜の」+他動詞が成立しないこと
- 全語と全接続詞形に、文を作れる相手が最低 1 つあること
- 自然さの指標が高い文ほど威力が高いこと
- 語の意味と部位の能力の対応、デバフだけの語が無いこと

さらに代表 40 語の全 3 語組 (244,800 通り) を標本検査します。
