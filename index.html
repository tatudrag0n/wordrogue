ステージクリア

遊び方

1. 文がそのまま武器の名前になる

並べるだけ。語を自由に並べて文にする。 文がそのまま武器名 になり、10 文字まで。

  • 成立 …「焔」+「必」+「刃」→ 焔必刃
  • 文にする …「焔」を「斬」られた「硬」→ 焔を斬られた硬
  • 並べ替え … 文の中の語はドラッグで自由に入れ替えられる
  • 不成文 … 実質語が足りない / 日本語として壊れている / 分割できない → その武器は無効

成立条件は「語が辞書で完全に分割できて、実質語（接続詞でない語）を 2 つ以上含み、 日本語として文になっていること」。 自然なほど、完成しているほど、文の力が上がる（属性で始まり・格があり・述語がある）。

2. 武器語は自分で得る

攻撃を決める武器語（剣 銃 弾 環 …）は 自動で付かない。武器語はレベルアップの 3 択に 他の語より低い確率で出る。

  • 刃・剣・刀・斧・戈・牙・爪 → 斬撃 ／ 銃・玉・矢・針・弓・槍・矛・球 → 射撃
  • 弾・塊・岩・石 → 爆弾 ／ 環・輪 → 軌道 ／ 鞭・鎖 → 薙ぎ
  • 壁・網・盾 → 城壁 ／ 珠・還 → 還り刃 ／ 雷 → 連鎖 ／ 光 → 光線
  • 武器語を文に置くと、その武器語が攻撃を決める。武器語どうしは隣り合えない

最初は武器が 1 つだけ。戦闘中に武器語を得ると 新しい文を作れる。持てる武器は最大 3 つ、各文は 10 文字まで。

3. 語の種類

  • 属性 … 火・氷・雷・毒など。色と状態異常が決まる。
  • 形態 … 剣・銃・弓・弾・矢・球・環・壁など。武器語。語彙からは引かれず、武器の攻撃を決める
  • 効果 … 貫・裂・散など。数値を上げる。
  • 動詞 … 燃 貫 凍 など。1 枚で 1 つの動作になる。
  • 接続 … る の られた など。語ごとに付く送り仮名が決まっている。 直前の語に結合する（下項）。
  • 自身 … 頑・走など。プレイヤーに効く。

4. 接続詞は語の横。タップで切り替える

接続詞は語の後ろに付く。語を並べ替えても、その語と接続詞は一緒に動く。 文の中の語をタップするたびに、その語に付く接続詞が 使えるものだけ切り替わる。 一周すると「接続詞なし」になり、また最初の接続詞から戻る。

例: 斬 なら る → られた → り → なし、 凍 なら る → える → なし と回る。

  • 接続詞は語ごとに決まっている … 語はそれぞれ自分の送り仮名（接続詞）を持ち、 それだけが付く。名詞は の を に へ。 斬 は 斬る 斬られた 斬り、 滑 は 滑らかな 滑る、 静 は 静かな 静かに。 「斬された」「凍ける」のような日本語に無い形は出てこない。 語彙の語はかならずどれかの接続詞に付く（行き止まりは無い）
  • 接続詞は消費しない。語の横にあるだけなので、何度でも付け替えて使える
  • 連体（斬る 速い 妙な）と の のあとは名詞。 連用（速く 妙に 斬り）のあとは動詞か形容。 「速く剣」「妙に剣」は不成立
  • 「〜を」のあとには動作が要る …「焔を剣」は不成立。「焔を斬る剣」なら成立
  • 宙に浮くと不成立 … 接続詞は直前の語にだけ付く。 「刃剣」も日本語に無いので不成立。 そのときは属性や効果の語（青 焔 必）を間に入れる
  • 同じ接続詞を 2 回使ってもよい …「風の潮の銃」は成立する。ただし少しくどいので文の力がやや下がる
  • 語彙はすべて漢字 1 文字。動詞も「燃える」ではなく「燃」「斬」の ように 1 個の漢字にして、送り仮名は接続詞で付ける
  • 並べ直したいとき … 文の右上の「空にする」で 語をまとめて語彙へ戻せる。語をひとつ戻したときの理由や、 接続詞を切り替えたときにその語に使える接続詞の一覧が下に出る。 10 文字不入らないときは「文字まで」と理由が表示される
  • 熟語を作ると専用効果が乗って、文の力がさらに上がる。 例 毒蝕弾 (毒 + 蝕 + 弾)。二字熟語は効果が小さめ。例 電熱 凍結
  • 熟語にも送り仮名が付く … 「発」「電」と並べると「電」に する が付けられて 発電する になる（「電する」は不成立）

5. プレイヤー自身も文にする

言葉鍛冶の一番上に自身の文がある。武器と同じく自由に並べるが、 文の末尾は「人」で固定。並べ替えても末尾は動かない。 「頑」+「走」なら 頑走人 のように称号になり、 文の力が攻撃と防御に効く。

6. 戦闘中はいつでも組み替えられる

Q で言葉鍛冶を開く。開いている間だけ時間が止まるので、 戦況を見てから並び替えられる。

7. ことばはレベルアップの 3 択でもらう

新しいことばはステージ終わりにもらいません。 戦闘中のレベルアップで入ります。引き直しボタンもありません。 出るたびに 3 個から 1 個選ぶ。7 秒以内に決めないと 上の候補から 1 個入る（時間は止まらない）。 接続詞は 3 択に出ない。文の中の語をタップすれば付け替えられる。

  • ふつうのレベルアップ … 3 択 1 個／1 / 5 / 9 … は自分の文に 1 個
  • 5 の倍数 … 3 択が 2 回（順に選ぶ）
  • 5 の倍数 … 自分の文の空きに 1 個（自動で入る）

語彙は 12 個から始まり、書庫で言玉を使い 「語彙」を買うと 1 個ずつ広がる（上限 30、次のステージへ持ち越す）。 武器語は他の語より出にくい。選ぶと新しい文ができる。

8. 満杯のときは自分で捨てる語を選ぶ

語彙が満杯で新しいことばが入らないときは、先に 捨てることばを 1 つ決める。語彙の一覧が全部出るので、 消していい語を自分で選んでから 3 択に進む。

選ばずに時間切れになると 一番古い 1 語が消える。 また、満杯のときは武器や自分の文から語を外せない。

9. 「忘れる」で語彙の空きを作る

言葉鍛冶の「忘れる」を押すとモードが点る。 このときは語彙の語をクリックするだけで 捨てられる。 武器や自分の文にある語は対象にならない（それらは「忘れる」られない）。

10. 語は自由に配置できる

言葉鍛冶では語を文のあいだへドラッグして置く。 文の中に並べた語はどこへでも移動でき、語彙へ戻せば外れる。 タップだけで組むこともできる。

  • 語彙 → 文 … 語を差し込む。語彙の空きが 1 つ減る
  • 文 → 文 … 並べ替え。どちらの語も消えない
  • 文 → 語彙 … 語を外す。満杯なら語彙の最古の 1 語を捨てる
  • 語彙の語をタップ … 語を持ち上げる。文の隙間をタップで置ける
  • 文の語の ✕ … 語彙へ戻す。語彙が満杯でもできる（最古の 1 語を捨てる）
  • 文の語をタップ … 後ろの接続詞が順に切り替わる
  • 文の語の右の接続詞マスをタップ … 使える接続詞を一覧から一発で選ぶ
  • 戻す … 直前の操作を 1 つ取り消す（最大 40 回）
  • 文の語を長押し … 持ち上げてからタップだけで並べ替えられる
  • 文は 10 文字まで。入りきらない語は置けない

11. ステージクリア報酬

ステージを終えると 言玉 がもらえる。 100 + ステージ番号 × 100 が基本で、 自分の文の力（攻撃と防御の倍率）で最大 2 倍まで増える。 倒しきれずに負けたときは半分以下。クリアしたら一旦ホームへ戻る。

ステージを終えたときの 3 択は 武器の追加 / 武器の強化 / 自身の文 / 休息。 ことばはここでは出ない。 新しいことばは戦闘中のレベルアップで得る。

12. 辞書

辞書を開くと、使えるすべてのことばを一覧できる。 カテゴリで絞り込んだり、名前で検索したりできる。 開いている間は時間が止まる。 形態（剣・銃・環 …）は武器語なので、語彙からは引けない。

  • 戦闘中 … HUD の 「辞」 ボタン
  • 言葉鍛冶の画面 → 「辞書」 ボタン
  • 鍛冶の上から開いても、鍛冶は閉じない。閉じると元の画面に戻る
  • 語をクリックすると、鍛冶の下にその語の効果が出る

13. 敵も「文」でできている

敵の頭の上には敵自身の文が出ている。通常の敵は 2 語、 ボスは 3 〜 5 語。自分が作った武器の文でその語を斬り落とす。

  • 武器の文が成立 … 1 語斬る（確率 15%）
  • 熟語を含む … 2 語斬る（確率 45%）
  • 述語（接続詞の合成）がある … 2 語斬る（確率 45%）
  • 敵の文が不成文になると 「不成文」 と出て、 その敵は動かなくなり、ダメージの受けが 2.5 倍になる

つまりよく組んだ文ほど、敵の文を早く崩せる。 威力で押し切るのとは別の、ことばの作り方で勝つ道がある。 ボスは倒れない。崩しても攻撃パターンが止まるだけ。

14. 経験値の引き寄せ

敵を倒すと経験値が落ちる。近づくと引き寄せられるので、 拾いに行く必要はない。遠いところにあるものも時間切れでは消えない。 引き寄せの速さには上限があるので、通り過ぎたり振動したりしない。

15. 書庫 — 走った分が、次の走りに残る

ステージをクリアすると言玉が手に入る。 敵の文を崩すときにも貯まる（行動が止まるぶん強いので刻み多く）。 累計がタイトル画面に「文を崩した数」として出る。

書庫では恒久強化が買える。

  • 恒久強化 … 体力 / 攻撃 / 装甲 / 経験値 / 引き寄せ / 会心。各 6 〜 10 段階
  • 語彙 … 言玉で手持ちの語を 1 つ多く。最大 30 個
  • 段階を上げるほど値段が上がる。使い切りはできない
  • どれも次のランに持ち越す。死んでも失わない
